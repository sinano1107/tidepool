Decision-log line for the skim: a muted heading line (time · agent · short task id, full id on hover) above the one-line decision; objection annotations sit below at the same left edge. Tapping a row's body opens the single Object action (the objection annotations below it are outside that tap target); a completion's right-edge chevron opens its handoff. Completions get a grass fill; unread entries a teal left bar. When an objection has a cause, show that latest cause as read-only text on its own line below the objection comment; `uncertain` must say that the cause is not yet determined. The attribution's evidence (`causeEvidence`) follows the cause as read-only text. A `memory` cause names the memory entries the worker followed (`causeEntries`): render each id as a link on that line that calls `onOpenMemoryEntry`, never the row's Object.
