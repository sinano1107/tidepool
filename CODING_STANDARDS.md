# Coding standards

- **A comment whose why comes from a recorded decision names that decision** — `// ADR 0109 決定1: merge-back の前に昇格すると古い remote-tracking ref を読む`. ADR numbers and 決定N are citation addresses (`docs/agents/domain.md`), so the reference makes this code one of the citers counted before an ADR is rewritten or superseded; the why stays beside it so the reader does not have to open the ADR. A why with no recorded decision behind it carries no reference.
