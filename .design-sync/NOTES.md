- **2026-08-12, issue #260 solo phase — `[GENERAL]` fixed-position overlay wrapper collapse**: authoring `Dialog`'s preview (`position: fixed; inset: 0`) hit a real card-harness bug, not a component or config issue. `emit.mjs`'s `.ds-single`/`.ds-cell` wrappers set `transform: translateZ(0)` to contain `position:fixed` descendants (so they don't escape the card) — this makes the wrapper the CSS containing block for the fixed child, and per spec, out-of-flow descendants don't contribute to a block's `auto` height, so the wrapper collapses to 0 (plus the scrim's own `padding: var(--space-4)` ×2 = the 32px measured). `inset: 0` then resolves against that degenerate box, so the dialog renders vertically off-canvas (title clipped) — in BOTH the `?story=` grading capture and the shipped product card (verified both independently; not just a grading artifact). Confirmed via `getBoundingClientRect`/`getComputedStyle` on the live page (`.ds-sync/storybook/http-serve.mjs` + a throwaway playwright script), and via the `emit.mjs` comments themselves (§"Single-story renders sit in a transformed wrapper"). `emit.mjs` is off-limits to fork (app-contract surface) and no `cfg.overrides` knob addresses it — the fix lives entirely in the authored `.tsx`: **wrap the component in an explicitly-sized in-flow spacer div** (`<div style={{height: 500}}><Dialog>…</Dialog></div>`) so the transformed wrapper's auto-height picks up real content height instead of collapsing; the fixed child still contains correctly (that part works as designed), it just needs a non-zero box to resolve `inset:0` against. Verified: same fix repairs both the grading capture and the product card (same html, same mechanism). Composition, not reimplementation — same species as `FieldRow.tsx`'s layout `<div>`. Only `Dialog` uses `position:fixed` among all 21 components (`grep -l "position.*fixed" design-system/components/*/*.jsx`) — none of the remaining fan-out components need this, but the recipe is worth knowing if a future component (a Toast portal, a menu) hits the same pattern.
