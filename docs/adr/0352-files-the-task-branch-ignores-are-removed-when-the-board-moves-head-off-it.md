# タスクブランチが無視するファイルは、盤面が HEAD をそのブランチの外へ動かすときに消える

2026-11-02 の grilling(issue #2912、#2889 の finding)で決定。「clean」の述語(`git status --porcelain`、ADR 0084 決定3 の1つの綴り)は
HEAD の branch の ignore 規則に相対であり、4つの読み手のうち盤面自身が HEAD を動かした後に読む2つ(ADR 0345 決定3 の再実行の検査、
ADR 0351 決定5 の pickup の検査)と次の task の完了の門だけが、タスクブランチの `.gitignore` だけが無視していたファイルを「休止後に書かれた」
「commit せよ」と読む。同じ事象が盤面の1手(checkout)で正当と違反に割れていた。「休止位置で dirty ⇒ 休止後に書かれた」の推論は
「タスクブランチで clean なら休止位置でも clean」を誰かが保証していなければ成り立たないが、その持ち主がいなかった —— ADR 0345 が tree rule に
当てた原則(事後条件が自分の述語の前提を壊す手)そのものである。休止位置は根ではない: park を消しても次の pickup が `main` から
タスクブランチを切る瞬間に同じ形が出る。実測の表(今日・案A・案B、既存テストの赤)は #2912 のコメントに置く。

## 決定

1. **盤面が名前の場所で HEAD をタスクブランチの外へ動かす手は、動かす前の branch が無視しているファイルを消してから動かす。**
   merge back の帰り先への checkout、休止位置への checkout、次の pickup のタスクブランチへの checkout、quarantine 受理のやり直しの同じ手が
   その全部で、1つの helper(ignored だけの `git clean`、入れ子 repo も)を通る。保証を述語側(branch 非依存に書き直す・記録して除外する)
   ではなく HEAD を動かす手に置くのは、読み手を増やさないためである。worker がタスクブランチの `.gitignore` に書いたものは worker 自身の
   「成果物でない」宣言であり(ADR 0084、ADR 0276 決定2 と同じ側)、消して失うのは再生成の時間だけである。
2. **消すのは離れる branch が無視するもの全部で、行き先でも無視されるものも残さない。** 持ち主の文は1つ(「宣言したものは HEAD が離れる
   ときに消える」)で、休止位置の tree は head と一致する。session を越えた cache の持ち越しに価値を置いた決定は無く、残すと別の系譜の
   stale な生成物を次の task が抱え、ファイルの運命が「次に盤面がどの branch へ行くか」で変わる。
3. **範囲は名前の場所(workspace・面接室)で、解放の種類は問わない。** 上限到達の中断・escalate・decompose・回収も同じ休止位置を通り、
   再開した task は自分の ignored の生成物を失う —— 失うのは commit していないものだけで ADR 0084 の線と揃う。受験者の checkout は当てない
   (ADR 0276 決定1): 非対称の理由は「その checkout に、別の branch で tree を読む次の session が居るか」の1点である。
4. **退避の例外ではない。** ADR 0069 の「唯一の例外」が縛るのは WIP の外へ出られるもので、ignored ファイルは worker 自身の宣言で `add -A` の
   外に居り、消しても WIP に入るはずのものは1つも失わない。退避の後、HEAD を動かす手の中の別の step である。
5. **再実行の枝(HEAD が既にタスクブランチを離れている)では撃たない。** 1回目の HEAD の移動が消している。ADR 0345 決定3 の dirty 検査は、
   この決定の後は本来の意味(休止後の書き込み)だけを捕まえる。

## 退けた形

- **行き先でも無視されるものは残す**(#2912 triage の案A)—— 撮ってから消す2箇所の窓を持ち、持ち主が「行き先の規則」に依る。
- **消さずに記録して次の session の門と退避から除く**(同 案C)—— `add -A` まで含めて除く必要があり、読み手が増える。
- **述語を branch 非依存に書き直す** —— 4つの読み手全部が変わる。
- **休止位置を消す** —— 根ではない(上記)。人間が覗く checkout の理由(ADR 0052 決定7)もそのまま。
