# 異議が修理子を生むのは直す成果が残る task だけで、cancel は review の付帯子を倒さず、受験者は採点以外を盤面に残さない

**Status 追記: 決定6 の「流し読みの root の行に Interview の印を出す」は ADR 0273 決定10 で、Interview ごとのグループの見出しに昇格した** —— root と監査 review の行は workspace のグループでなく Interview のグループに出る。決定1(受験者の行は出さない)はそのまま(2026-10-18 の grilling、issue #2184 / ADR 0273)。

2026-10-16 の grilling(issue #2109)で決定。`src/triage.ts` と `src/retrospective.ts` は Interview を知らず、受験者と root への異議から
本番どおり修理子と RCA が生えていた —— 修理子は pin を持たず表の行で走り、着地しないはずの Interview から PR を開きうる(#1886 / #2108)、
受験者の下の RCA が書く Knowledge は他の受験者に届く(#2085)、受験者の帰責は root の状態を見ずに学習器へ入る(#1913)。洗い直しで、
親の直接 cancel が ADR 0198 決定3 の守った RCA review を黙って倒し、cancel の後に打った異議の RCA は走るという非対称も見つかった。
実測の表と `file:line` は #2109 のコメントに置く。

## 決定

1. **受験者のエントリへの異議は受け付けない。** `raiseObjection` が拒み、流し読みに受験者の行を出さない(root の history と task の面では
   読める)。Interview の観測は root の採点1本である(ADR 0181 決定4)—— 人間が答案の判断行に下す判定は、採点と同じ問いに別の経路で
   答えるだけで、採点への不服は採点者(root)の判断行へ向ける。ADR 0049 が「走行中の行を流し読みから隠す」を退けた理由は異議の機会の
   喪失だったので、機会の無い行には当たらない。
2. **受験者は記憶を書かない。** 記憶を書く verb を受験者の verb の差し替え(ADR 0122 決定2、`decompose` と同じ場所)で外し、受験者の
   書き込みのための機構(ADR 0264 決定1 の「受験者の書き込みを外す」半分、決定4 の一木の門の例外、人間の面の印)は消す。ADR 0263
   決定7 が verb を残した根拠「本番と違う条件を作る」は、0263 自身が伏せる理由と認めた2つ(測られていると知らせる・対象どうしを
   そろえない)のどちらでもなく、採点されるのは成果物で書き込みは副作用である。原則は1文 —— **受験者が盤面に残すのは答案の採点だけ**。
3. **修理子が立つ(残る)のは、直す成果が盤面に残る task だけ。帰責と RCA は成果の有無に依らない。** root の出題・採点の行への異議は
   修理子を立てない(出題を直す道は root の retry、ADR 0267 決定4。採点への不服は決定1 のとおり)が、RCA と candidate の起草は本番
   どおり —— root の agent は本番の agent で、その判断の学びは本番の記憶である(ADR 0264 決定3)。cancelled の task への異議は帰責と
   RCA だけ立てる。ADR 0049 根拠1「異議の効果は異議されたタスクの状態に依らない」は done と走行中の対称を言ったもので、帰責と RCA は
   引き続き状態に依らない —— 依るのは修理子だけで、捨てた成果に修理は無い。
4. **cancel の cascade は、親が待っている子と、成果が親のブランチに帰る付帯子(修理子)を倒し、系譜に透明な付帯子(review、
   ADR 0053)は残して走る。** 直接 cancel・root の retry・failure question の abandon のどれでも同じ。線は型の列挙ではなく性質 ——
   帰り先のブランチが死ぬ成果を持つか —— で引く。review は親の判断ログを読んで findings を書き、第2回の帰責(ADR 0115 決定2)へ
   届ける仕事が親の生死で変わらない。これで ADR 0198 決定3(RCA は規則が要求する入力で、人間は直接 cancel できない)が親経由でも守られ、
   cancel の前後で異議の帰結が揃う。
5. **受験者の下には question 以外何も生えない。** domain の `registerTask` が扉を問わず拒む(ADR 0245 決定1「人間の扉を含めて分けない」
   の延長)。root は本番の review task と同じく付帯子(異議由来の RCA、人間が名指しで登録する review 子)を受け、work の子は今どおり
   拒む(ADR 0253 決定5)。ADR 0267 決定1 の「root の下に生えるのは対象であって task ではない」は「対象と付帯子」に改める。
6. **流し読みの root の行には Interview の印を出し、異議の操作で修理子が立たないことを予告する。** 行の題は probe の題で、印が無いと
   人間は Interview の行と知らずに方向コメントを書く。

## 退けた形

- **受験者への異議を帰責だけ残し、root が done の Interview に限って学習器に数える**(最初の推奨)—— 採点と同じセルに入る第2の採点経路で、
  帰責の Board call を行ごとに払う。
- **修理子を Interview の木に入れる**(pin を継ぎ、答案の写しから分岐させる)—— 捨てる答案を直す機構を作る。
- **root への RCA も立てず、異議を注釈にとどめる** —— 決定3 の理由で、root の agent の学びの経路を retry のコメント(1件の Interview
  にだけ渡る)だけにする。
- **付帯子を全部残し、帰り先の無い修理子は「閉じた根に塞がれた子」(ADR 0265 決定6)として pickup が飛ばす** —— あちらが skip を選べたのは
  reopen の道があったからで、cancelled の根には無く、人間が片づけるまで残る修理子を毎回置く。
- **受験者の書き込みを視界の述語で外し続ける** —— 新しい agent の読み手ごとに述語を通し忘れる種類の漏れが残る(#2085 はその形)。

## 帰結

- #1913 の問いは経路ごと消える。`resolveTaskBranchLineage` の「ブランチの無い受験者の祖先を飛ばす」分岐にはどの task も届かなくなる。
- `interviewLeftEmpty` は root 自身の未決着の子も数えるので、開いた RCA を持つ root は最後の対象を外しても自動では cancel されない。

## 追記(2026-10-17 の grilling、issue #2152 / ADR 0271)

決定3 の「成果が盤面に残る」の判定は task 自身の status から「cancelled の work の祖先を挟まない」に広がり、決定4 の線は「review の付帯子は
全部残る」から「仕事の宛先が親の生死に依らない付帯子(RCA)だけ残る」に引き直された —— 祖先の cancel が届いた done の work の完了時レビューと
人間登録の review 子は倒れる(ADR 0271 決定1・3)。

## 追記(2026-10-17 の grilling、issue #2150 / ADR 0272)

決定3 の「成果が盤面に残る」は task ではなく行の成果の帰り先で判定する。記憶の書き込みの行(ADR 0252)の成果は記憶の店に残るので、
cancelled の task と Interview の root の記憶の行への異議も修理子(`memory_repair`)を立て、決定4 の cascade はそれを倒さない —— 「帰り先の
ブランチが死ぬ成果を持つか」の線はそのままで、型(work)で近似していた判定を文言に揃えた。
