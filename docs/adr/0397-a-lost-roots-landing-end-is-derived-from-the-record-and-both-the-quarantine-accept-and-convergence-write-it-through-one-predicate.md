# 失われた根の着地の終わりは記録から導き、Quarantine の受理と収束が同じ判定で書く

**Status 追記: この ADR は ADR 0407 が全部置き換えた —— 着地の終わりは書かず、効いている失われた event から読む。終わりを書く判定も、受理と収束の2人の書き手も、決定4 の順序も無くなる。開いている着地の question は、受理が失われた event と同じ transaction で閉じる([ADR 0407](0407-a-task-whose-branch-is-lost-reads-as-landing-ended-no-ending-record-is-written-and-the-give-up-closes-its-landing-questions-with-the-lost-event.md) 決定1・2、2026-11-23、issue #3582)。**

2026-11-21 の grilling(issue #3492)で決定。ADR 0375 決定9 は、着地の終わり(決定7)と question を閉じる処理(決定8)を give-up の受理の書き戻しと一緒に書くとした。#3298 は根の判定を書き戻した後の ref で読むために(同 決定6)、終わりを別の transaction に移した。そのうえで、終わりを書く処理は、その回答が失った `task/<id>` の一覧(メモリ上の差分)だけを読んでいた。実測(#3492 のコメント)で、この形は2箇所で漏れると分かった。(1) 書き戻しが落ちるか盤面が落ちると差分が消え、失われた event は残るのに根を読み直す者がいなくなる。(2) 親が生きている間に失われた死んだ子は、受理の時点では根でない。しかし親が着地した後に根と読まれ、収束が失われたブランチを git で読み、生のエラーで昇格失敗の question を立てる。そのとき受理はもう来ない。根であることは受理の後からでも成り立つので、決まった時点で1回だけ書く形では、どこに置いても漏れる。

## 決定

1. **着地の終わりは記録から導く。** 対象は、効いている失われた event を持ち、`done` で、PR を開いておらず、着地の終わりの記録が無い work である。根かどうかの読み・透明の読み・終わりの種類は ADR 0375 決定6〜8 / ADR 0380 のままにする。判定は1つの関数に置く。
2. **workspace の Quarantine の受理は、選択肢を問わず、その workspace の対象全部に判定を当てる。** 戻す選択肢は書き戻しの後に、戻さない選択肢は1回目の比較を通った直後の同じ同期区間で当てる。どちらも ref が基準と一致した後なので、根を読み違えない。開いている着地の question を回答の帰結として閉じる処理(ADR 0375 決定8)は、受理だけが持つ。面接室の Quarantine は対象にしない。
3. **収束は、着地の根と読んだ候補に失われた event が効いていれば、着地させる前に判定を当てて終わりを書く。** 失われたブランチは git で読まない。その根に開いている昇格失敗の question があれば当てず、受理に任せる —— question を閉じるのは受理だけで(決定2)、まだ答えていない失敗 question を盤面が先回りして潰さない(ADR 0240 決定2)。
4. **受理は、着地の終わりを書いた後で Quarantine を閉じる。** 書き戻しが落ちても Quarantine は開いたまま残り、次の受理が来る。回復はこの順序に依るので、テストで固定する。

ADR 0375 決定9 のうち、決定8 を書き戻しと一緒に書く部分を、この ADR が置き換える。決定1・4(event と倒す処理)を書き戻しより先に書く点は変えない。spec #3273 group H の「終わりは受理が刻む」からも外れる —— 書く場所は受理と収束の2つになり、判定は1つになる。

## 帰結

- 受理のたびに、その workspace の古い失われた event も読み直される。前の受理で根でなかったために終わりを書かれなかった task も、今は根と読まれれば終わる。決定7 の条件は状態で書かれているので、これと食い違わない。

## 検討した選択肢

- **受理だけが書く** —— 受理の後で根になった子を拾えない(上の (2))。
- **収束だけが書く** —— 開いている local 着地の question を持つ根は収束の候補から外れるので、(1) の根に届かない。
- **系譜を基準の値で読み、失われた event と同じ transaction で終える** —— (1) は消えるが (2) は残る。加えて、基準の sha に差し替える入力を系譜の読みに足すことになる。
