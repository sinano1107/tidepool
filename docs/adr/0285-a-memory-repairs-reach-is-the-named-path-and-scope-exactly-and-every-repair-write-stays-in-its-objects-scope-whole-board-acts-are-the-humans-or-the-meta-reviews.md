# 記憶の修理子の射程は名指された (path, scope) そのもので、修理子の書き込みは対象の scope に留まる —— 盤面全体への行為は人間か meta-review の仕事

2026-10-20 の triage / grilling(issue #2330、元 #2329 の /code-review)で決定。ADR 0282 決定4 は判断の行の修理子の射程を「名指された
(path, scope) と、同じ path の盤面全体」とし、根拠は覆いの門(ADR 0161 決定6)と形を揃えたことだけだった。盤面全体への行為は重ねた1本の木
(ADR 0178)の設計上、必ず全 workspace に効く —— 改名は配下の行を連れて行き(ADR 0177 決定5)、定義の `supersedes` は同じ path の
workspace の定義を畳み(ADR 0177 決定6)、定義は未定義だった workspace の枝を定義してその項目を閉じる。charts の枝の行に打った異議の修理子
が、盤面全体の定義と盤面全体の改名の2手で docks の leaf を動かし、`supersedes` で docks の定義を置き換えられた。ADR 0282 の目的(退けた案1
「人間の異議の意図と違う workspace の同名の枝を動かせることを機構で止める」)の取りこぼしで、効き方ごとに門を足す形では効き方が増えるたびに
穴が増える。実測(`file:line`)と効き方・箇所の表は #2330 のコメントに置く。

## 決定

1. **判断の行の修理子の射程は、名指された (path, scope) そのもの。** 盤面全体の枝に `define_memory` / `move_memory_branch` が届くのは、
   判断の行が (path, 盤面全体) を名指すときだけ。ADR 0282 決定4 の射程の文を改める —— 被覆の文(盤面全体への行為はどの scope の項目も覆う)
   は meta-review 自身の行為の数え方で、そのまま。
2. **`memory_repair` の書き込みはすべて対象の scope に留まる。** 移動(`move_memory` / `move_memory_branch`)の行き先の scope は移動元と同じ、
   畳み(`fold_memory`)と定義の `supersedes` の後継の scope は畳まれる各エントリと同じ。書き込みの射程(ADR 0281 決定2・ADR 0252 決定4)で
   通った対象も同じ —— 「盤面全体へ広げる向き」は meta-review の門であって、修理子には開かない。元に戻す操作(`restore_memory` /
   `restore_memory_branch`、門なし)は今のまま。盤面全体へ広げる・盤面全体に書くのは人間(settings / 管理 MCP)か meta-review の仕事で、
   方向コメントがそれを求めるなら修理子は `log_decision` で人間に戻す。

## 退けた案

- **効き方ごとに門を足す** —— 盤面全体の改名が名指されていない scope の行を運ぶなら拒む、`supersedes` が名指されていない scope の定義を
  畳むなら拒む。3つ目の効き方(定義が他の workspace の項目を閉じる)が残り、効き方が増えるたびに門が増える。
- **異議で再掲された枝(ADR 0284)の例外** —— 盤面全体のエントリがその path の下にあり一木の門が workspace の定義を拒む状態でだけ、盤面
  全体の定義を射程に入れる。その状態では構造の項目 (path, 盤面全体) が隣に並び、人間はそちらに異議を打てる。狭い行だけに打った取り違えは
  修理子の `log_decision` と次の周期の項目で1周期で直る。守るものに対して、盤面の状態で射程が変わる規則は釣り合わない。
- **盤面全体の改名だけを射程から外す** —— 定義と `supersedes` の効き方が残る。
- **名指された scope の行だけ運ぶ** —— 置き去りの workspace の leaf が定義の無い旧 path に残る、ADR 0177 決定5 が避けた形。

## 変えないもの

meta-review は射程を持たず、盤面全体への行為は自分の周期の判断で行う。一木の門(ADR 0178 決定2)と、盤面全体の枝の改名が全 workspace を
連れて行く(ADR 0177 決定5)はそのまま —— 書き込みが盤面全体の枝を作った・そこへ移したときの修理子の改名は盤面全体を名指しているので、
今までどおり全 workspace を運ぶ。

## 帰結

- 追記する ADR: 0282 決定4、0281 決定2、0279 追記3、0284 退けた案3、0252 決定4。
- 修理子の拒否文は射程の拒否(`requireBranchReach` / `requireNamed`)と同じ形 —— 規則と対象だけを言い、「どこで言うか」は持たない(#2293 の線)。
