# workspace の削除の扉は、完了した work の下にいる未決着タスクも参照に数える

2026-10-10 の grilling(issue #1729)で決定。ADR 0226 決定2 が数えの外として #1729 に置いた経路の決着。付帯子の決着は
完了した work の祖先をすべて着地し直し(ADR 0092 決定3)、そのたびに祖先の workspace を解決する。子は親と違う workspace
にいられるので(分解の子の明示、review の分解子としての registry-edit — ADR 0031、人間の門の明示)、扉が数える
「X を参照する未決着タスク」にも「X の着地を待つ完了タスク」にも入らない子が、扉を通して消した X を quarantine に
落とせた。abandon promotion 済みの祖先では、立て直された昇格の question の `retry` が、PR を開き終えた祖先では回答を
待たずに `land()` が落とす。再現と経路は #1729 に置く。

## 決定

1. **未決着タスクは、自身の workspace に加えて、決着したときに着地し直す完了した work の祖先の workspace も参照する。**
   workspace の削除の扉は、それを既存の「X を参照する未決着タスク」として数える。人間が待つか cancel するのは、
   その未決着タスクそのものだからである。祖先が abandon 済みか、PR を開き終えたかは見ない。PR を持たずにもう着地した
   祖先(local merge question が立った、着地する内容が無かった)は着地し直されないので数えない — 扉が拒むのは
   quarantine を作る削除だけで、何も壊れない削除を拒めば人間は review を cancel するしかなくなる。
2. **agent 名の参照は広げない。** 着地し直しは profile を読まない — 開いている PR への push も昇格の question の立て直しも
   読まず(ADR 0217 決定3 / ADR 0225 決定3)、読むのは面を開く時点だけで、その状態は着地を待つ完了タスクとして
   すでに数えられている。workspace だけが、着地し直しのたびに最初に解決される。
3. **扉の外で消えた workspace を着地し直しで解決できないときも「変わった」と読み、昇格の question を立て直す。**
   ADR 0225 決定1 の「読めなければ変わった」を、head が無い場合から解決の失敗にまで明示的に広げる。再発火は一度きりで
   走査は無く(ADR 0092 決定3)、quarantine の解除は再発火をやり直さないので、question を立てなければ、その間に来た
   修理が黙って消える(ADR 0105 決定3)。`retry` が失敗した回答は拒まれ、question は開いたまま残るので、エントリを
   戻してから答えれば通る。

## Considered options

- **門と再発火の範囲を、同じ workspace の子孫に絞る** — 別 workspace の子孫が決着するまで着地しないのは門の正しい
  働きで、門で止まった祖先は子孫の決着による再発火が無ければ着地へ進めない。
- **異なる workspace の付帯子を人間の門と Edit で拒む** — 塞げるのは人間の門の経路だけで、分解の子と registry-edit の
  経路は残る。人間の門の食い違い(別 workspace の review は親のブランチを見られない)は #1737 で扱う。
- **祖先を「着地を待つ完了タスク」として数える** — abandon 済みや PR を開き終えた祖先は着地を待っておらず、
  agent の扉と quarantine の解除が共有する語の意味が変わる。
- **PR を持たずに着地済みの祖先の下も数える** — 決定1 の理由で退けた。
- **解決に失敗したら question を立てず quarantine に落とす** — 決定3 の理由で退けた。quarantine と question の両方は、
  人間の修理が変わらないので足さない。
