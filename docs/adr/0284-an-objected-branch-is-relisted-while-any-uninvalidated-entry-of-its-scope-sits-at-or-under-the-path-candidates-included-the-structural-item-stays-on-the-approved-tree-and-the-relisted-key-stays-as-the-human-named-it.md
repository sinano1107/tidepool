# 異議された枝の再掲は、その scope の無効化されていないエントリ(candidate も)が path かその下にある限り載り、構造の項目は approved の木のまま、再掲の鍵は人間が名指した (path, scope) のまま

2026-10-20 の triage / grilling(issue #2331、元 #2329 の /code-review)で決定。異議された枝の再掲(ADR 0279 決定5)の「生きている」は
枝の一覧(ADR 0122 追記 #1209 —— approved で未無効化のエントリだけが枝を作る)で読まれていて、異議された (path, scope) の配下に
無効化されていない candidate しか残らない周期では、その枝が Items to judge に載らず、修理子が直さなかった異議の帰結が黙って落ちた。
同じ「エントリがある」という語が、枝の一覧の読み(approved)と一木の門の読み(candidate も、ADR 0178 決定3・ADR 0282 決定3)の
2つに割れていて、再掲はどちらに乗るかを決めていなかった。実測と `file:line` は #2331 のコメントに置く。

## 決定

1. **異議された枝の再掲の「生きている」は、その scope の無効化されていないエントリ(状態を問わず、candidate も)が path かその下に
   あること** —— 枝ごとの移動(`move_memory_branch`)が運ぶ集合そのもので、ADR 0282 決定3 が盤面全体で読んでいる集合と同じ。根拠は
   届く verb: meta-review の `define_memory` は門を持たずその (path, scope) に定義を書け、枝ごとの移動は candidate も運ぶ。判断の手が
   2本届く対象を項目から外せば、人間が名指した枝の帰結が安全網から落ちる。配下が移されていれば今の (path, scope) で載る(ADR 0279
   決定5 の読みのまま、candidate の移動の鎖も辿る)。再掲の枝は枝の一覧に無い path でもよい。
2. **構造の項目「配下にエントリを持つ定義の無い枝」は approved の木のまま**(ADR 0122 追記 #1209 の線を変えない)。candidate を数えれば、
   起草されたばかりの candidate が新しい path に1つあるだけで定義の項目が立ち、その candidate を木に入れるかの判断より定義の判断が先に
   来る。再掲と違うのは、人間が名指していない枝だから。
3. **再掲の鍵は人間が名指した (path, scope) のまま、盤面全体のエントリがその下にあっても盤面全体に写さない。** 構造の項目を盤面全体の
   1つに畳む(ADR 0282 決定3)のは「届く手が1本の項目は判断でなく強制」だからで、再掲の枝には scope の中の移動の手が残る。構造の
   (path, 盤面全体) と再掲の (path, workspace) が並んでも、盤面全体の定義はどちらも覆う(ADR 0282 決定4)ので二度申告にはならない。

項目の生死を分ける述語は、エントリの側も枝の側も「届く verb がある対象か」で引く(ADR 0278 追記5・ADR 0282 決定3 の線)。本 ADR は
枝の側だけを決め、エントリの側で鎖の末尾が無効化済みのものをどう扱うかは #2324 で決める。

## 退けた案

- **数えない —— 配下の candidate 自身が項目なので、その判断に畳まれる** —— candidate が承認されれば翌々周期に構造の項目で枝は出るが、
  それは「定義が無い」の項目であって「移すべきだった」という異議の帰結は拾わない。決定5 は修理子が直さなかったときの安全網で、人間が
  名指した枝を周期で待たせたら安全網の意味が無い。
- **構造の項目も candidate を数えて揃える** —— 決定2 のとおり。ADR 0122 追記自身が「ADR 0178 の門が candidate を数えるのは理由が違う」
  と2つの読みを置いており、揃える根拠にならない。
- **再掲を構造の項目と同じく盤面全体に写す** —— 人間がどの枝に異議を打ったかが項目から消え、修理子の射程(名指された (path, scope) と
  同じ path の盤面全体、ADR 0282 決定4)とも形がずれる。

## 帰結

- 追記する ADR: 0279 決定5、0282 決定2・3。枝の一覧(ADR 0122 追記 #1209)は変えない。
- 再掲の項目が名指す path は Branches の部分に無いことがある —— その枝の中身は Live candidates の部分で読む。
