# PR を閉じる判断と断念は根の内容だけを覆い、子孫の帰り先は lineage が決める

**Status: 決定3 の「PR が開いている根の子孫も lineage に任せる」は ADR 0265 決定3 で置き換えた — PR が開いている根の子孫は、その根が内容で終わるまで記録で候補から外す。閉じた根と断念した根の子孫(決定1・2)は今どおり lineage に任せる**

2026-10-14 の triage / grilling(issue #1850)で決定。収束は、盤面の外で閉じた PR の根と断念した根(ADR 0225)の子孫を、
「子孫はその根が運ぶ」として候補から外していた(spec #1839)。だが閉じた根には push せず(ADR 0241 決定3)、断念した根
には撃たないので、どちらの根も子孫を運ばない。根の内容が別の経路で保護ブランチに届いた後に完了した修理は、lineage の
上では自分で根になるのに候補に入らず、PR にも question にも出ないまま着地しない。実測(既存テストでの固定)とコードの
照合は #1850 のコメントに置く。

## 決定

1. **PR を閉じる人間の判断が覆うのは、閉じた時点の根の内容だけである。** 閉じた後に完了した子孫の行き先は、ほかの
   子孫と同じく lineage が決める。根の内容がまだ保護ブランチに無ければ、子孫は閉じた根のブランチへ帰り、どこにも
   出ない —— 閉じた根への修理は閉じる判断の内側であり、問い返さない(ADR 0229 決定3)。根の内容がすでに保護ブランチに
   あれば、子孫は自分で根になり、自分の面を開く —— 直す相手は保護ブランチにある内容で、閉じた PR とはもう関係がない。
2. **断念した根の子孫も同じく lineage に任せる。** 根のブランチへ帰る子孫は根の内容を変えるので、断念の問い直し
   (ADR 0225)で人間に戻る。保護ブランチへ帰る子孫は自分で根になる。断念は「この内容を盤面で運ばない」という答えで
   あって、保護ブランチにある内容への修理まで黙らせるものではない。
3. **これで、着地の終わっていない根(PR が開いている・閉じた・断念した)の子孫は、どれも記録で外さず lineage に
   任せる。** PR が開いている根の子孫は #1842 の実装ですでにこの形である。ADR 0241 の帰結(閉じられた PR の木や断念した
   根の木の子は毎回候補に残り、費用はその木の数に比例する)は、この決定の形をそのまま述べている。

## 退けた案

- **閉じる判断は閉じた後の子孫まで覆う(今のまま)** —— 保護ブランチにある内容への修理が黙って消える。
- **閉じた木で完了した内容は、どちらの場合も question で人間に見せる** —— 根のブランチへ帰る場合に、閉じたことを
  問い返す形になる(ADR 0229 決定3 が退けた形)。
- **断念した根の子孫だけは記録で外したままにする** —— 根のブランチへ帰る場合はすでに問い直しで人間に戻っており、
  外す記録が効くのは保護ブランチへ帰る修理を黙らせる場合だけである。
