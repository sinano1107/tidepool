# ref を読めなかった git の答えは「無い」ではなく「分からない」—— その場所の資源の停止で1回止まり、読み口は呼び手に選ばせない

2026-11-26 の triage と grilling(issue #3910。#3867 の triage で族の根として分けた)で決定。

git は、壊れた ref ファイルや packed-refs の壊れた行を読めないとき、warning だけを出して exit 0 で件を落とす。何も言わずに落とすこともある。1つの ref を読む `rev-parse --verify --quiet` は、壊れた ref で「無い」と同じ exit 1 を返す。盤面の呼び手の大半はこれを見ずに「無い」として判断していた。その結果は次の4つである。比較は壊れた ref を「削除された」と名指す。他の task のブランチの拒否と巻き戻しの検査はすり抜ける。出元 repo への送りは黙って漏れる。タスクブランチが無いと読んで fork 元を選ぶ。#3826 で読み口 `gitListing` が入ったが使うかは呼び手の任意で、大半の読みは使っていなかった。ADR 0409 は同じ線を、戻す先の object の判定に限って書いていた。呼び出し口の表と git の実測は #3910 に置く。

## 決定

1. **ref を読む git の答えでは、git が何かを報告して件を落とした答えや道具の失敗を「無い」と読まない。** ref を並べる読みにも、1つの ref を読む口にも当てる。表示だけの読みも除かない —— 壊れた ref を黙って落とした一覧は、人間に誤った一覧を見せる。ADR 0409 決定1・2 の「無いと積極的に分かったものだけを無いとする」を、ref の読み全般へ広げる。
2. **読めない ref は、その ref がある場所の資源の停止で1回だけ止まり、「削除」「移動」「無い」としては名指さない。** 名前の場所なら workspace の Quarantine、作業台なら読めない作業台の拒否(ADR 0382 決定2)、盤面が持つ写し(registry clone・面接室)ならその資源の停止で止まる。pickup の比較・最初の撮り・収束・release のどこで読んでも、同じ1つの止まりに落ちる。理由は読めない ref を名指す。ADR 0403 決定2 の「出口は失敗の中身で決まり、起きた位置では決まらない」と同じ線である。
3. **人間が叩く扉(受理・作業台の complete と take-in・workspace の更新・publish)で当たったときは、その扉が ref を名指して拒むだけで、資源の停止は立てない。** 扉の前の人間は拒否文で失敗を知る(ADR 0403 決定3 と同じ線)。扉が Quarantine も立てると、直して叩き直すたびに回答待ちの question が1つ挟まる。worker の verb で当たったときは、ADR 0424 決定2・3 のとおり failure question を立てて session を回収し、資源の停止は観測者(後始末・pickup の門)が立てる。資源の停止を自分で立てるのは、無人の過程(pickup・収束・release)だけである。
4. **読めない ref が1つでもある間は、`restore the baseline` も give-up も拒む。** 出口は人間の手での修理だけである。壊れた loose ref は git がどのみち書き換えを拒む。packed-refs の壊れた行は書き換えが通るが、上書きで直す道を残すと、壊れた `refs/stash` の reflog を keep-around に持たずに書く経路が開いたままになる。ADR 0409 決定1 の「上書きの選択肢は足さない」と同じ線である。
5. **出元 repo へ最後に push した値の記録(ADR 0422 の fork ごとの記録)が壊れて読めないときは、push せず昇格の失敗にする。** ADR 0376 決定2 の「値が読めなければ push する」は、記録が「読めて、無い」とき(初回・未記録)に狭める。壊れた記録を無いと読むと、人間が出元 repo で巻き戻したブランチを push で上書きする。これは ADR 0422 が防いだ形である。
6. **ref を読む git の読み口は、呼び手に選ばせない。** 素の git で ref を読むことを機械の検査で禁じる。どの検査にするかは spec が決める。読み口があっても選ばない呼び手が残ることから、この族は生まれた。

## Considered Options

- **判断に使う読みだけに広げる** —— 「判断に使うか」を呼び出し口ごとに見分ける線になり、呼び手の任意が形を変えて残る。
- **点修正(#3867・#3827・#1865・#3310・#1832 を別々に)** —— 同じ形の6件目がまた出る。
- **扉でも資源の停止を立てる** —— 人間が前にいる回に question を重ねる。
- **壊れた ref を基準の値で上書きする出口を残す** —— 上の決定4の理由で採らない。
