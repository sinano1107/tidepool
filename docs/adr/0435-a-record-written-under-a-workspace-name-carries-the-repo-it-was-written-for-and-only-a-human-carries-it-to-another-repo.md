# workspace の名前で書いた記録は書いた時点の repo を伴い、別の repo へ続けるのは人間の引き継ぎだけ

2026-11-27 の triage と grilling(issue #3950、元は #3929)で決定。

盤面は長く残る記録の多くを workspace の名前で書き、読むときに名前を今の登録と読む。名前は 削除の扉 → 登録し直し(ADR 0378
決定9)で別の repo を指しうるが、削除の扉は記録を消さない。登録し直した後、旧い repo の記憶が新しい repo の worker に注入され、
学習器の成績と routing の材料が混ざり、旧い task の未解放の checkout と merge back が新しい repo の git を書き換えうる。ADR 0399 が名指した根(根の repo の代わりに今の名前の値)を、PR(ADR 0399)・issue
(ADR 0430)と読み手ごとに塞いできた族の残りである。読み手の表は #3950 に置く。決定はコードの読みに依り、走らせたものは無い。

## 決定

1. **名前で書いた記録は、書いた時点の宣言の repo を伴う。** 読む口はそれを今の宣言と比べ、食い違えば旧い記録として扱う ——
   注入しない、集計に入れない、git を動かさない、承認で効かせない。記録の種類ごとに鍵を変えない(memory・学習と統計・task の運び)。
   旧い task の未解放の checkout と merge back が新しい repo を動かさないのも、この比較による。
2. **片方でも repo が無ければ、書いた時点の保護ブランチの commit が今の checkout の履歴に含まれるかで比べる。** ローカルで生まれた
   workspace(ADR 0066)と origin の無い checkout の記録は repo を持たない。publish と path の移動は履歴が同じなので続き、同じ名前で
   作り直した別の project は切れる。checkout を複製して育てた2つの間では、複製の前の育ちだけを共有し、その後の一方の育ちは他方に
   続かない。保護ブランチの履歴を書き換えると切れ、人間が引き継ぐ。
3. **別の repo への継続と改名の継続は、人間の明示の引き継ぎだけ。** 登録の扉に任意の「引き継ぐ元」を置き、既定は引き継がない。
   登録の後も、移動の扉で食い違う記録の枝を今の登録へ移せる。引き継ぎは memory と学習・統計の記録を一緒に運ぶ —— 「同じ
   project の続き」という判断は1つである。引き継ぐ元が今も登録中なら(複製の元)、移さずにその時点の写しを作り、以後の育ちは
   互いに共有しない。
4. **孤立は「scope の記録が今の宣言と食い違う」も含む。** 同じ名前が登録し直されていても一覧に印が付く(ADR 0173 決定5 の延長)。
   宛先の agent 名の孤立は名前の線のまま。
5. **承認は、食い違う記録を拒む。** memory の candidate は付け替えるか reject し、routing 提案の Interview は提案ごと reject する
   (ADR 0173 決定3 と同じ形)。

## 退けた形

- **記録は登録(登録の扉から削除の扉まで)に属し、削除の扉で切れる** —— grilling で一度採ったが、ADR 0430 が退けた
  「登録の世代」と同じ線で、path を移すだけの登録し直し(ADR 0373 決定14)のたびに記憶が切れ、人間の引き継ぎを要する。
- **名前で続ける(今のまま)** —— 別の repo で名前を使い回すと黙って注入され、人間は気づけない。
- **削除の扉で記録の行方を選ばせる** —— 間違いの出口に扉も選択肢も足さない ADR 0378 決定9 とぶつかり、判断の材料
  (次に何を登録するか)は登録の扉にある。
- **publish の扉が記録の repo を書き換える** —— ADR 0399 が task の記録で退けたのと同じく書き手が増え、process が死ぬと
  巻き戻しが走らない。
- **repo が無ければ path で比べる** —— 盤面が作る checkout は規約の場所(置き場 + 名前)に置かれ、path の比較は名前の比較になる。
- **repo が無ければ履歴の根(最初の commit)で比べる** —— 複製して育てた2つの間で、複製の後の一方の育ちが他方に続く。
- **削除の扉が未解放の checkout と届かない merge back で拒む** —— 完了 task の後始末は ADR 0421 決定4 が既に拒み、届かない
  merge back で拒むと扉が永久に止まりうる(0421 の「待てば通る拒否」に反する)。新しい repo を動かさないことは決定1 で足りる。
- **祖先の記録が食い違う task を止める** —— ブランチを切る子は ADR 0419 決定5 が分かれる元と比べ、削除で着地が終わった祖先の
  下は ADR 0421 決定3 が帰り先の無い系譜として扱い、ブランチに依らない子は ADR 0430 決定3 が止めないと決めている。

## 帰結

- ADR 0430 の「記録が無ければ読まない」は issue の線のまま。この決定は記録の種類を広げるだけで、比べ方(ADR 0378 決定4 の綴り)を共有する。
- 権限 profile の `allowed_workspaces` が名前で続くことは registry の設定の話で、この決定の外に置く(派生 issue)。
