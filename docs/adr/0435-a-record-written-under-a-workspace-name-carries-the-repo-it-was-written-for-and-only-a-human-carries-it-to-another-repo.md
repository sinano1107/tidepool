# workspace の名前で書いた記録は書いた時点の repo を伴い、別の repo へ続けるのは人間の引き継ぎだけ

2026-11-27 の triage と grilling(issue #3950、元は #3929)で決定。

盤面は長く残る記録の多くを workspace の名前で書き、読むときに名前を今の登録と読む。名前は 削除の扉 → 登録し直し(ADR 0378
決定9)で別の repo を指しうるが、削除の扉は記録を消さない。登録し直した後、旧い repo の記憶が新しい repo の worker に注入され、
学習器の成績と routing の材料が混ざり、旧い task の未解放の checkout と merge back が新しい repo の git を書き換え、旧い祖先の
下の新しい task が新しい repo で走る。ADR 0399 が名指した根(根の repo の代わりに今の名前の値)を、PR(ADR 0399)・issue
(ADR 0430)と読み手ごとに塞いできた族の残りである。読み手の表は #3950 に置く。決定はコードの読みに依り、走らせたものは無い。

## 決定

1. **名前で書いた記録は、書いた時点の宣言の repo を伴う。** 読む口はそれを今の宣言と比べ、食い違えば旧い記録として扱う ——
   注入しない、集計に入れない、git を動かさない、承認で効かせない。記録の種類ごとに鍵を変えない(memory・学習と統計・task の運び)。
2. **片方でも repo が無ければ path で比べる。** ローカルで生まれた workspace(ADR 0066)の記録は repo を持たない。publish は
   path を変えないので続き、ローカルのまま path を移すと切れる。
3. **別の repo への継続と改名の継続は、人間の明示の引き継ぎだけ。** 登録の扉に任意の「引き継ぐ元」を置き、既定は引き継がない。
   登録の後も、移動の扉で食い違う記録の枝を今の登録へ移せる。引き継ぎは memory と学習・統計の記録を一緒に運ぶ —— 「同じ
   project の続き」という判断は1つである。
4. **孤立は「scope の今の宣言が、書いた時点の repo と違う」も含む。** 同じ名前が登録し直されていても一覧に印が付く(ADR 0173
   決定5 の延長)。宛先の agent 名の孤立は名前の線のまま。
5. **承認は、書いた時点の repo が食い違う記録を拒む。** memory の candidate は付け替えるか reject し、routing 提案の Interview
   は提案ごと reject する(ADR 0173 決定3 と同じ形)。
6. **削除の扉は、未解放の task の checkout と届いていない merge back があれば拒む。** 盤面が運ぶものの残る間は拒む
   (ADR 0421)線の写し漏れで、新しい決定ではない。
7. **祖先の記録の repo が今の宣言と食い違う task は、今の登録で走らせず止めて人間に見せる。** 旧い repo の文脈で起草された
   修理子や RCA を別の repo で走らせない。

## 退けた形

- **記録は登録(登録の扉から削除の扉まで)に属し、削除の扉で切れる** —— grilling で一度採ったが、ADR 0430 が退けた
  「登録の世代」と同じ線で、path を移すだけの登録し直し(ADR 0373 決定14)のたびに記憶が切れ、人間の引き継ぎを要する。
- **名前で続ける(今のまま)** —— 別の repo で名前を使い回すと黙って注入され、人間は気づけない。
- **削除の扉で記録の行方を選ばせる** —— 間違いの出口に扉も選択肢も足さない ADR 0378 決定9 とぶつかり、判断の材料
  (次に何を登録するか)は登録の扉にある。
- **publish の扉が記録の repo を書き換える** —— ADR 0399 が task の記録で退けたのと同じく書き手が増え、process が死ぬと
  巻き戻しが走らない。

## 帰結

- ADR 0430 の「記録が無ければ読まない」は issue の線のまま。この決定は記録の種類を広げるだけで、比べ方(ADR 0378 決定4 の綴り)を共有する。
- 権限 profile の `allowed_workspaces` が名前で続くことは registry の設定の話で、この決定の外に置く(派生 issue)。
