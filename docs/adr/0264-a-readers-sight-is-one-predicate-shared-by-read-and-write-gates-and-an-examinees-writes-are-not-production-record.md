# 読み手の視界は読みの門と書き込みの門が共有する1本の述語で決め、受験者の書き込みは本番の記録ではない

2026-10-16 の grilling(issue #2053)で決定。ADR 0263 決定7 は受験者(Interview の pin の子)が読む面だけを決め、#2018 はそれを
読みの3門(INDEX と注入・search の候補・read の視界)に別々に足した。書き込みの門(定義の衝突・一木の門)、meta-review の材料と
専用 verb、人間の面、採点者(Interview の root)はどれも除外を知らず、受験者が書いた Knowledge と Definition は本番の worker に
注入され、受験者の書き込みを畳んだ後継は受験者にも届いた(#2012・#1933・#2032・#2028)。読み手と門の照合表は #2053 のコメントに置く。

## 決定

1. **受験者の書き込みは本番の記録ではない。** Interview は受験者の産物を他に何も残さず(ブランチは消え、PR は無い)、書き手は品質を
   測っている最中の model である。Knowledge も Definition も、agent の読み手 —— 本番の worker の注入と pull、meta-review の材料と
   専用 verb(`list_memory_entries` / `read_memory_entries` / `search_memory_entries`)、Board call の起草が組む INDEX —— の視界に無い。
   人間の面にだけ、どの Interview の対象が書いたかの印つきで残る(削除は無い、ADR 0083 決定5)。ADR 0122 決定1 の「`list_memory_entries`
   は人間の面と同じ一覧」は「受験者の書き込みを除いた同じ一覧」に改める —— verb に残すと meta-review が畳み、後継が本番に入る。
2. **読み手の視界は読み手ごとに1本の述語で決め、門ごとに残す差は種別の絞りと報告の形だけ。** 層は3段 —— approved・scope・読み手に
   無い集合、そこに宛先、さらに未無効化。search が Definition を当てないこと(ADR 0083 追記7)、見えない行を search は落とした理由で、
   read は無効化の鎖で、INDEX は黙って伝えることは変えない。SQL に残るのは FTS の照合と粗い前絞りだけで、正本は述語の側。
3. **受験者の視界に無いものは3つの和。** 他の pin の子の書き込み、Interview の root の書き込み、出所が Interview の木(root か pin の子)の
   event にあるエントリ。どの Interview のものでも、本文が同じ後継(移動・復元の複製)を含む。root の書き込みは本番の記録に残る ——
   probe の組み方の学びは次の root と本番の正当な記憶で、受験者に伏せる理由は「測られていると知らせる」(ADR 0263 決定2)だけ。
   meta-review が畳んだ後継(出所は meta-review の decision)は追わない —— 畳みの本文は meta-review の著作で、人間の自由文と同じく語の
   検査では塞げないと ADR 0263 が認めた線に乗る。
4. **書き込みの門も同じ視界で見る。** 視界に無いエントリは拒否にも名指しにも出ない。書き手の視界に無い生きた Definition が同じ scope・
   path にあれば、新しい Definition が盤面の手でそれを superseded にして通る —— 「1枝1定義」(ADR 0178)は保ち、走る順番で
   できることが変わらない。読み手の視界に無い後継による無効化は、その読み手には起きていないものとする —— escalate で止まった受験者が
   戻ったとき、自分の定義は生きて見える。一木の門(ADR 0178)も視界で見るが、受験者の書き込みはどの書き手にも数えない —— 0178 決定3 の
   「盤面全体のエントリすべて」を「いつか agent の木に現れうるもの(candidate を含む)」と読み替える。0178 が全部を数えた理由は
   「見えるものだけを数えると承認の瞬間に禁じた形ができる」で、ここで外す集合は書き手と出所で決まり状態で変わらないので当たらない。
   残る形(受験者の定義の上下に盤面全体のエントリ)は agent の木には現れず、人間の面にだけ受験者の印つきで見える。
5. **worker の記憶の verb は `supersedes` を受けない。** 置き換えるのは盤面(決定4)・meta-review・修理 task で、worker ではない。
   今は inputSchema に無いだけで釘が無かった(#2012 の実測)ので、server 境界で釘を打つ。
6. **採点者には差を見せる。** Interview の root の注入と pull では、受験者の視界に無いエントリに英語の印(`not shown to examinees`)を
   付ける。root は Interview を知ってよい読み手なので漏れにならず、rubric を書くときと採点のときに受験者に無いものを求めないと判断できる。
   印が無いと、受験者が読めない記憶に従わなかった答案が rejected として同じセルの観測(ADR 0181 / 0210)に数えられ、採点結果から
   見分けられない。本番の worker の面は変えない。

## 改めるもの

- **ADR 0178 決定3** —— 一木の門が数える「盤面全体のエントリすべて」は、受験者の書き込みと、書き手の視界に無いものを含まない(決定4)。
- **ADR 0122 決定1** —— meta-review の `list_memory_entries` が返す一覧は、人間の面と同じから受験者の書き込みを除いたもの(決定1)。

## 退けた案

- **採点で accepted になった対象の書き込みだけ root の完了後に本番へ入れる** —— 採点は handoff を見るので書いた記憶の正しさは見ていない
  (ADR 0253 決定4)。root 完了で見え方が切り替わる機構も要る。
- **受験者の書き込みも本番の記録と読む** —— 受験者は本番の既定 agent として本番の checkout で解く(ADR 0253 決定3)が、「学んだ事実は
  真である」は書き手の品質が分かってから言えることで、Interview はまさにそれを測っている。
- **書く時点で Interview の event を出所に選べなくする** —— 次の Interview の root は本番の読み手で、probe の組み方の Exemplar や root 宛ての
  Behavior は正当な用途になる。
- **エントリは見せ case だけ受験者用に描き直す** —— Exemplar の注釈の anchor は case からの逐語引用で、注釈の text も人間の自由文。
- **root の視界を受験者に揃える** —— root に一番価値のある記憶(過去の Interview の学び)を奪う。
- **書き込みの門は全部を見たまま拒否文から id だけ外す** —— 拒否そのものが見えない定義の存在と走る順番の差を知らせる(ADR 0263 決定2 の
  両方の理由に当たる)。一木の門だけ全部を見る案も同じ理由で退けた —— 経路(受験者が、Interview の木を出所にする盤面全体のエントリの
  上の path を define する)は狭いが漏れの形は同じ。
- **書き手の視界に無い Definition を数えず並べて通す** —— 同じ scope・path に生きた Definition が複数でき、人間の面と移動・復元の門が
  複数を扱う形になる。
