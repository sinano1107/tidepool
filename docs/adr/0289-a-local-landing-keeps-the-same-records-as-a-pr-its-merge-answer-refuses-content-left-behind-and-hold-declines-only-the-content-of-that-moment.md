# ローカル着地も根に記録を持つ —— merge 回答は積み残しで拒み、hold が断るのはその時点の内容である

2026-10-21 の grilling(issue #1780、発端は #1769 / ADR 0231 と #1777 / ADR 0239)で決定。purely-local の着地は、merge の
執行・hold・終わりを根に刻まず、local merge question の行が存在することを収束の除外条件にしていた(ADR 0241 帰結)。PR
着地が後から得た記録の規律(ADR 0231 / 0236 / 0242 / 0265)はローカルに写されていない。そのため、ローカル着地の merge
回答は門だけを読み、修理の merge back が conflict して workspace が quarantine に落ちた間に merge と答えると、修理を
欠いたまま保護ブランチへ merge され、解いた修理はタスクブランチに残って question も収束の撃ちも無い。hold の後に届いた
修理も同じく誰にも見えない。4つの interleaving の実測は #1780 に置く。

## 決定

1. **ローカル着地は PR 着地と同じ記録の規律に乗る。** merge の回答は、根の id に執行の記録を回答と同じ transaction で
   刻み(ADR 0265 決定1 の形)、収束はその記録で根を終わらせる。hold の回答は、その時点のタスクブランチの head を根に
   刻む(ADR 0225 決定1 の形)。収束が候補から外すのは、開いている local merge question を持つ根、hold の head から
   内容が変わっていない根、merge の記録がある根の3つで、question の行の存在では外さない(ADR 0241 帰結の線を置き換える)。
2. **ローカル着地の merge 回答も積み残しで拒む。** 述語は ADR 0239 のままで、比べる head は着地の面が merge する
   head —— PR では GitHub が報告した head(ADR 0242 決定1)、ローカル着地ではローカルのタスクブランチ。拒否は
   question を開いたまま残し、運ぶ面を名指しする(ADR 0240 決定5)。workspace の quarantine 単独では拒まない(PR の
   回答と同じ)。この読みは fetch を持たず I/O の await を挟まない —— ADR 0288 決定2 の「ローカル着地の merge は
   同期」は保つ。
3. **hold が断るのはその時点の内容である。** 刻んだ head から内容が変わっていれば(ADR 0105 の述語。head が引けなければ
   変わったと読む)、門が開いてから local merge question を立て直す(推奨は merge —— 届いた内容は求められた修理)。
   もう一度 hold と答えれば head が刻み直される。ADR 0053 決定3 の「恒久の着地しない」は改める。未着地ブランチの一覧
   (ADR 0053 が退けた受け皿)は作らない。

## Considered options

- **merge した根は内容で終わる(`nothing_to_land`)** —— merge した事実と、もともと運ぶものが無かった事実が同じ記録に
  なり、purely-local の根の着地の状態(#2138)が出せない。突きのたびに git で比べる費用も残る。
- **question の行の存在で外し続け、回答にだけ積み残しを足す** —— hold の後に merge back された修理が無言で止まる。
  ADR 0105 決定3 の「修理が無言で消える経路は残さない」に反する。
- **回答で後始末の印を読む** —— ADR 0239 決定2 が退けた、事実が閉じる前に消える代理。
- **着地の形を1つにする(purely-local の着地をやめる)** —— 写し忘れは構造的に消えるが、すべての workspace に remote を
  要求する費用に見合う利点が無い。守りは面によらず根ごとに通ると決めれば足りる。

## 帰結

- hold の後に内容が変わった根は、門が閉じていても着地を待つ完了タスク(ADR 0217 決定4 / ADR 0226)に戻る。
- 着地 question の注釈が積み残しを報せない欠け(#1779)は、ローカル着地の question にも及ぶ。
- purely-local の根の着地の状態(#2138)は、決定1 の記録から導ける。
- 積み残しの拒否文が名指しする運ぶ面に、落ちた後始末の確認 question が無い欠けは PR 側にも今日あり、別 issue に置く。
