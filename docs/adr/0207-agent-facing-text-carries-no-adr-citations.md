# エージェントが読む地の文に ADR の引用を入れない

2026-10-07、issue #1429 で決定。registry の定義の検査や実行設定の扉が返す拒否文に `(ADR 0110 決定1)` の形の引用が
入っており、triage はこれを「決定」だけ英訳して残す案を推していた。

## 決定

1. **エージェントが読む地の文(system prompt・tool 記述・tool の出力・拒否文)には ADR の引用を入れない。引用はその文を
   組み立てるコードのコメントに置く。** ADR はこのリポジトリの保守者向けの記録で、盤面の上で走るエージェントにはどう頑張っても
   辿る経路が無い。辿れない参照は読み手の判断を何も変えず、トークンと時間を使い、意味を推し量らせて判断を乱しうるノイズに
   なる。プログラムを読む人間にとっての手がかりという価値は、コメントに置いても失われない。
2. **これは ADR 0015 とは別の線である。** ADR 0015 が決めたのは地の文の**言語**で、ここで決めるのは**中身**(読み手が辿れない
   参照を含めない)である。英訳しても解決しない —— `ADR 0110 decision 1` も辿れなさは変わらない。
3. **人間が読む文(WebUI・question の本文など)の引用をどうするかは、ここでは決めない。** 人間は ADR を読めるが、盤面を使う人が
   このリポジトリの保守者とは限らない。既存の引用を読み手ごとに仕分けるのと合わせて #1508 で決める。

## 退けた代替案

- **「決定N」を `decision N` に訳して引用を残す**(triage の推奨)。言語の線は守るが、辿れない参照というノイズは残る。
- **前例に揃える。** 文字列の中で ADR を引く箇所は `src` に42か所あったが、そう決めた記録は無く、前例は根拠にならない。
