# 盤面が出元 repo へ最後に push した値は fork ごとに repo id で持ち、出元 repo の変更で忘れない

2026-11-26 の triage → grilling(issue #3851)で決定。盤面が出元 repo へ最後に push した値は写し `refs/remotes/head-repo/task/*` で、
出元 repo の変更の前方向の畳みが全部を消していた(ADR 0415 の前提)。そのため出元 repo を A → B → A と戻すか、外した後で A を置き直すと、
盤面は A に送ったことを忘れる。写しの無いことを「送ったことが無い」と読む読み手が2つあり、どちらも人間が A で祖先へ巻き戻したブランチを
fast-forward で元へ戻す —— 宣言の扉の送出(ADR 0395 の #3605 の Status 追記)と、PR が無いか未記録の根の収束の巻き戻しの検知(ADR 0376
決定6 は写しが読めなければ止めない)。前者は domain 層のテストで再現した(上書きされた)。後者と PR の記録のある根の扱いはコード読みで、
経路は #3851 のコメントに置く。

## 決定

1. **#3605 の守りは、前に使った fork へ戻る場合と、外した後に置き直す場合も含む。** 盤面が送った事実を盤面の側で忘れたことは、人間の
   巻き戻しを上書きしてよい理由にならない。
2. **最後に push した値の記録は fork ごとに持ち、出元 repo の差し替えでも外しでも消さない。** 扉の送出と収束の巻き戻しの検知は、宣言中の
   fork の記録を読む。宣言中の fork に記録の無いブランチは、今どおり初めての送出である。宣言中の fork の id を盤面が覚えていなければ、
   扉も収束もその fork へ push せず理由を言う(fail-closed)—— 出元 repo は扉からしか宣言されず扉は必ず id を読むので、欠けるのは記録の
   欠落か扉の外の編集だけで、「無い」を「送ったことが無い」と読む穴を id の欠落で開け直さない。止まりは workspace の軸で1回 —— 扉の外で編集された出元 repo(ADR 0395 決定2、#3560)と同じ
   止まりに入り、出口は扉での宣言し直しである。根ごとの question にはしない(ADR 0403 決定4)。
3. **記録に消す契機を足さない。記録は checkout に属し、削除の扉と登録し直しでも消えない。** 今も写しを消すのは出元 repo の変更の畳み
   だけで、それをやめれば記録は checkout と同じだけ残る。削除の扉が残す checkout とタスクブランチ(ADR 0087)と同じ側で、登録し直した
   workspace が同じ fork を宣言すれば記録が効く —— fork 上のブランチは削除の後も残り、人間が手を入れうる。数はタスクブランチ(恒久記録
   —— ADR 0066)× 使った fork で、「古くなったら忘れる」は同じ穴を時間で作り直す。
4. **記録の鍵は fork の GitHub の repo id である。** 名前の変更や持ち主の移動は同じ fork と読み、消して同じ名前で作り直した fork は別の
   fork と読む —— どちらも fork の中身との対応が名前より正しい。ADR 0399 が退けた「repo を id で記録する」の理由(PR の無い所・読めない
   所には比べる相手が無い)は当たらない。比べる相手は GitHub の応答でなく、扉が宣言のときに読んで盤面が覚えた id である。ADR 0399 が
   改名で受け入れた限界(開いた PR を持つ根が止まり、人間が終える)はそのまま残る —— 止まるのは安全側で、名前を鍵にして起きるのは
   止まりでなく巻き戻しの上書きである。
5. **ADR 0415 を取り下げる。** 前方向の畳みは消す写しを持たなくなり、行を書くだけの畳みになる。出元 repo の変更も repo と同じく
   ADR 0391 の形(予告 → 書く → 行き先の検査が人間を待たずに畳む)に戻り、扉が途中で死んだ後の人間の回答は要らない。

## 退けた案

- **扉の送出に「出元 repo に無いこと」の lease を足す。** 扉が送らなかったブランチを、写しの無い収束が同じ巻き戻しの上から push する。
- **今どおり消し、消した fork を記録してその fork への push を止める(fail-closed)。** 「どの fork を忘れたか」に fork ごとの記録が要るうえ、
  守りは決定2 と同じで、戻るたびにブランチごとの回答が増える。
- **鍵を `owner/name` にする。** 名前を変えた fork で全部を送り直し、決定1 の上書きが人間の改名で戻る。

## 帰結

- Status 追記: ADR 0376 決定3、ADR 0395 の #3605 の追記。取り下げで、ADR 0415 が ADR 0395 決定2 と ADR 0403 決定4 に入れた追記を外す。
- ADR 0415 の帰結の「扉の最後の畳みが落ちたときの WebUI の文面は #3592 が持つ」は、畳みが ref を書かなくなるので前提が無くなる。
- 未測定: PR の記録のある根で、戻った扉が `task/<root>` を記録無しに PR の head へ送る経路(コード読み)。決定2 の記録で扉は送らなくなる。
