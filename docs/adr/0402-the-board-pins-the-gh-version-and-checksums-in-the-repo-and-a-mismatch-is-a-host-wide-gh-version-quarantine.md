# gh の版と checksum は repo に固定し、版の不一致はホスト単位の「gh の版」の Quarantine にする

2026-11-23 の grilling(issue #3272)で決定。VM の盤面は gh を Ubuntu の apt から入れていた。apt の gh は 2.46.0 のまま版を
指定できず、盤面が PR を読む `--json` の欄 `baseRefOid` を知らない。そのため VM ではどの PR も無人 merge されなかった(#3564 の
実環境確認)。maintainer は実運用(#1879)の前に gh を最新版へ固定すると決め(2026-11-22)、REST へ書き換える案は採らなかった。
この ADR はその固定の形と、盤面の検査を決める。実測と触るファイルは #3272 のコメントに置く。

## 決定

1. **固定の版と checksum は repo の1か所に置く。** repo 直下の `gh-cli-version` に、版と、arch(arm64 / amd64)ごとの公式リリースの
   tarball の sha256 を書く。導入は公式リリースの tarball を、この sha256 で検証してから入れる。同じリリースの `checksums.txt` で
   検証する形は退ける。tarball と同じ出所から落とすので、出所の差し替えを防げないからである。版の正本を repo に置き、導入と盤面の
   コードの両方がそこを読む形は、ADR 0186 決定5 と同じである。
2. **盤面は gh を撃つたびに、撃つ前に版を読み、完全一致を確かめる。** 範囲は許さない。起動時に1回だけ確かめる形は退ける。ADR 0186
   決定3 と同じ理由で、盤面の稼働中に人間が gh を入れ替えたのを見逃すからである。版が読めないこと(gh が無い・`--version` の
   失敗・時間切れ)も不一致と同じに扱う。観測できないことを一致と読まない。
3. **不一致は、ホスト単位の資源「gh の版」の Quarantine である。** 確認型の question は Tidepool 名義で1枚だけ立てる。受理の検証は
   版の読み直しである。一致した gh の呼び出しが1つ通れば、回答なしで決着する(ADR 0184 決定5 の形)。開いている間に止まるのは
   gh を撃つ行為だけである。
   - GitHub を読む task の pickup。ADR 0328 決定2 の集合で、通常の task は流れ続ける。
   - 着地の poll と無人 merge の tick。question も failure も作らずに待つ。agent 名の Quarantine が着地を待たせるのと同じ形である。
   - gh を撃つ人間の verb。版の不一致を名指しして拒む。

   盤面全体へは抜けない。gh を要らない task という、止めるより狭い単位があるからである(PR を開くのは REST で、gh を撃たない)。
4. **版の不一致は ADR 0328 の展開失敗の streak に数えない。** 数えると、同じ原因に `issueExpansion` の question が重なる。
   版の不一致は確定的な故障で、天候ではない。
5. **版を上げるのは、手順書に名指しした測り直しを通した意図的な変更に限る。** 測り直すのは、`--match-head-commit` の merge、
   盤面が読む `--json` の欄、`pr create` の stdout が URL の1行であること、名前の場所を cwd にした gh がローカルの ref を動かさない
   こと(#3169)である。最後の1つは実 GitHub の使い捨て repo が要り、CI では回せないので、手順書で人が回す。機械の適合試験は
   作らない。

## 退けた案

- **公式の apt リポジトリから版を指定して入れる。** apt の外の署名鍵とリポジトリを足すうえ、`apt upgrade` で版が動きうる。
- **型付きの失敗を今の経路に流す。** 着地の PR の数だけ merge question が立ち、文面も「PR head を比べられなかった」と誤った原因を語る。
- **git も同じ形で固定する。** 門の上で git の版差が何かを壊した観測がまだなく、Ubuntu の apt の git は版を指定できない。
  別 issue に分けた。

## Consequences

- Mac で直接走らせる盤面と、作り直す前の Pi は、固定の版の gh を持たないので「gh の版」の Quarantine に落ちる。門は Mac の VM での
  実稼働なので、これを受け入れる。
