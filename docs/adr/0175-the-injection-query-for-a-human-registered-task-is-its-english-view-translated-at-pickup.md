# 注入の関連 leaf は、人間が登録した task では pickup 時に訳した英語の view で引く

**Status 追記: 決定3 の「人間が登録した task だけ」は ADR-0194 決定6 で改訂済み** —— 訳すのは、人間が登録した task か、登録の記録に異議の材料を持つ task(表示言語が English でない盤面でだけ、は不変)。RCA review が盤面の名義になっても、purpose に人間の方向コメントを運ぶためである。

2026-09-30 の triage / grilling(issue #1171)で決定。索引の正文は英語だけ(ADR 0015 四度目の精密化、issue #1052)だが、
spawn 注入の関連 leaf を選ぶ query は task の title / purpose / 完了基準で、人間が登録した task ではペイロード(原語)である。
表示言語の既定は Japanese なので、既定の盤面では人間が登録した task の関連 leaf がほぼ常に空になる。実測と `file:line` は
issue #1171 のコメントに置く。識別子が CJK に接すると当たらない欠陥は別件(issue #1178)。

## 決定

1. **人間が登録した task の関連 leaf は、task の文面の英語の view で引く。** view は表示時翻訳と同じ Board call・同じ cache で
   作る。保存される task は原語のままで、worker が読むのも原語 —— view は query にしか使わず、worker にも人間にも見せない。
   ADR 0015 の「翻訳は view」の内側にあり、ペイロードの線は動かない。誤訳の害は、関連 leaf がポインタなので的外れな行が
   並ぶ止まりである。
2. **訳すのは pickup 時、spawn の前。** title / purpose / 完了基準を1つの文面として1回で訳す。cache の鍵は文面の hash なので、
   編集された task は次の pickup で訳し直され、同じ task の後続 session は cache に当たる。issue-backed の task は文面が
   pickup 時に決まるので、訳せるのもここだけである。
3. **訳すのは、人間が登録した task を、表示言語が English でない盤面で、だけ。** 境目は誰が書いたか(ペイロード / 地の文)で
   引き、盤面は言語の判定を持たない。表示言語は AI 下書きが書く言語で、Memory の原文に付く言語でもある —— 人間が書いたものを
   表示言語で書かれたものとみなす線は既にあり、English の盤面のペイロードは英語とみなす。
4. **訳せなければ原語で引く。** 撃たなかった場合も撃って失敗した場合も spawn は止めず、撃ち直しの機構は持たない ——
   同じ task の次の session が、cache に無ければ撃つ。
5. **注入の記録が、何で引いたかを持つ。** `memory_injected` は、view で引いたときはその英語の文面を、訳す対象だが訳せなかった
   ときは理由(`throttled` = 撃たなかった / `failed` = 撃って失敗)を持ち、対象外なら欄を持たない。query が task の文面から
   導けなくなるので、`memory_pulled` の `input` と同じく記録の側に置く —— cache は記録ではない。
6. **異議のあとの起草に渡す注入節は spawn 時の view を再利用し、翻訳を撃たない。** view が無ければ原語で引く —— そのとき
   worker も原語で引いている。

## 帰結

- English の盤面に他言語で書いた task は原語で引かれる(この決定の前と同じ)。
- 翻訳の Board call が使えない盤面(Provider `anthropic` を持たない単独運用)は常に原語で引き、その事実は決定5 の理由として
  session ごとに残る。
- 人間が英語で書いた task でも、English でない盤面では Board call が1回走る。

## 退けた案

- **機構を足さず worker の `search_memory` に任せる** —— 既定の構成に、英語で書いた task には関連 leaf が出て日本語で書いた
  task には出ない差が残る。
- **多言語の埋め込み stream(issue #589)を待つ** —— 供給元が未決。来れば言語差も吸収するが、この決定を妨げない。
- **登録・編集時に先に訳す** —— 得るのは初回 spawn の待ちだけで、編集のたびに撃ち直す口と spawn に間に合わない競合が増え、
  盤面が無人のときにも Board call を撃つ。
- **文字(非 ASCII)で訳す対象を見分ける** —— ラテン文字の非英語が漏れ、盤面が言語の判定を持つ。
- **訳せなかった事実を専用の失敗 event に書く** —— 先例の失敗 event が別建てなのは撃ち直しの判定に使うからで、ここには
  撃ち直しが無い。
