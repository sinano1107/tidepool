# 付帯子の review の workspace は最も近い固定済みの祖先に従い、列は pickup でだけ書かれ、食い違う明示は拒む

2026-10-21 の grilling(issue #1737、出どころは #1729 / ADR 0234 の退けた案)で決定。人間の門から親を名指して登録した
review 子は、盤面が自分で登録する付帯子(完了時レビュー・RCA・修理子・Interview の監査)と違って親の workspace を写す段を
通らず、列が NULL のまま pickup で既定 workspace の名前を書かれ、親の成果物の無い場所で走っていた。親と違う workspace を
明示した review 子も受理され、親のブランチを自分の checkout で探せないので保護ブランチを土台に走る。再現と読み手の全件は
#1737 に置く。

## 決定

1. **付帯子の review は自分の workspace を持たず、列が非 NULL の最も近い祖先に従う。祖先に無ければ既定。** 登録時に
   親の列を写さない —— 列が書かれるのは pickup の瞬間だけ(ADR 0233 決定2 の線)。親と同じ名前の明示は受けて保存しない。
   登録の event は workspace を記録しない(ADR 0233 決定4)ので、保存しないことで消える記録は無い。
2. **祖先と違う名前の明示は、domain の `registerTask` が扉を問わず拒む**(ADR 0245 決定1 の形)。固定済みの祖先が1つも
   無いときも明示は拒む —— 揃える相手が無い。別の workspace を見たいニーズには、親を持たないルート review(独立監査)が
   既にあり、誰の着地も止めない。付帯子の review は親の読みの面を継ぐ(ADR 0273 決定4)、の1規則に揃える。
3. **Edit は付帯子の review の workspace を変えない。`""` も拒む。** 付帯子の review は既定への参照を持たないので、
   「空に戻せば既定へ付け替わる」(ADR 0233 決定5)は当たらない。
4. **pickup の埋めは「最も近い固定済みの祖先 → 既定」の順で、どちらから埋めたかを pickup の event に分けて記録する**
   (ADR 0233 決定4 の延長)。
5. **pickup 前に workspace を読む読み手は、同じ導出の述語で読む** —— 削除の扉、直接 cancel の quarantine の門、資源停止の
   門(ADR 0273 追記 / issue #2265)、段の選択、人間面の表示。ADR 0234 決定1 の「X を参照する未決着タスク」は導出で X に
   着く付帯子を含む —— 含めないと、PR 無しで着地済みの祖先の下の review 子が、扉を通して消した X で走ろうとして quarantine
   に落ちる。
6. **範囲外。** 分解の子が登録時に親の列を写すこと(ADR 0031 は別 workspace の明示を許す)、固定値を持つ子と親の Edit の
   食い違い、pickup の埋めを全子に広げて未固定の祖先にも書くか —— いずれも「列は固定の事実か写しか」という前提の問いで、
   族の根 #1796 の主題。

## Considered options

- **登録時に親の列を写す(盤面の付帯子と同じ形)** —— pickup 前の親の Edit で写しが食い違い、それを拒む門がもう1つ要る。
  写しの書き込み点を増やす方向で、#1796 が問う前提の上に積むことになる。決定1 の形は前提を変えても残る部分だけである。
- **人間の門だけで拒む** —— ADR 0245 決定1「人間の扉を含めて分けない」に反し、domain 層で釘を打てない。
- **違う workspace を許したまま、review の系譜に親の workspace の checkout を使わせる** —— review が2つの場所を持つことに
  なり、quarantine と封じ込めの単位(ADR 0273 決定8)が崩れる。
