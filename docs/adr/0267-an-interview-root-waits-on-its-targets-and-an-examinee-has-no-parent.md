# Interview の root は対象を待ち、受験者は root の子ではない

2026-10-16 の grilling(issue #2099)で決定。Interview は本番の task の木を乗り物にしていた —— root review が出題で work の
子を立て、子に pin を付けて受験者にする。木の前提(子は1つの仕事の部品で互いの成果を読む・親が指揮する・親は子が揃うと起きて
統合する)と Interview の前提(子は同じ問題の N 回の反復で互いを見ない・指揮は人間だけ・採点者は途中で何もできない)は反対で、
ずれが見つかるたびに「pin の子なら別」の分岐を足してきた(ADR 0245 / 0247 / 0248 / 0249 / 0251 / 0253 / 0263、#2013)。
実装の照合と分岐の一覧は #2099 のコメントに置く。

## 決定

1. **受験者は親を持たない work task で、root とは対象の行を経由してだけ結ばれる。** `parent_id` も `based_on_decision` も
   持たず、分解判断に乗らない。本番の木の規則(親の history・兄弟・前提の破綻・abandon の範囲・早期統合復帰)は何も掛からず、
   掛かるのは pin の規則(対象で走る・着地しない・分けない・記憶の視界)だけである。root の下に生えるのは対象であって task ではない。
2. **root は task でなく対象を待つ。** blocked の導出に「出題済みで、答案の task が未決着の対象を持つ」を1項足し、親が待つ子と
   同じ1本の述語に乗せる —— 表示・pickup・完了の門は引き続きその1本を共有する(ADR 0049 決定4 は保つ)。親子関係の外から
   blocked が出るのは盤面で初めてだが、待つ相手を task と言わないことで「独立した blocking エッジは無い」の線は越えない。
3. **root の cancel は対象経由で受験者に及ぶ。** 人間の直接 cancel、probe の破綻の報告への abandon / retry、最後の対象を
   外して空になったとき(ADR 0247)のいずれも、未決着の受験者を cancel し、その下の未回答 question は回答なしで決着する。
4. **probe の出し直しは root の人間の面に常時ある retry が担う。** 受験者は分解判断に乗らないので前提の破綻を宣言できず、
   probe の不備は escalation として1対象ぶん人間に届く(本番どおり、ADR 0263 決定9)。出題済みの root には question を待たず
   abandon / retry を置き、retry は決定3 の波及のあと ADR 0248 決定3 のもの(旧 root の id・probe・rubric・理由 = 人間の
   コメント)を新しい root に渡す。採点段階の報告(ADR 0251)は残り、その retry も同じ波及を使う。#2013 はこれで決着する ——
   回答画面から別の question へ回す扉は作らない。
5. **受験者の分岐元の head と workspace は、対象を経由して root の出題から引く。** `based_on_decision` を持たせて引く形は、
   分解判断に乗る task として前提の破綻の verb を呼び戻し、abandon の範囲が `parent_id = NULL` どうしの SQL の偶然で収まる
   形になるので採らない。
6. **表示は root の下に対象ごとに束ね、退出は root と一緒にする。** 親が無いと受験者は独立した木として done の瞬間に
   ボードから退くが、人間は Interview を1単位で読む。束ねるのは表示と退出だけで、親子の規則は入れない。
7. **受験者に見える構造の差は「decompose / redecompose が無い」だけに縮む。** 合成した親(ADR 0263 決定3)と兄弟隠し
   (決定4)、continue のコメントを伏せる規則(決定8)は、親も兄弟も前提の破綻も無いので消える。受験者は本番の親なし work と
   同じく自分の task だけを読む。決定10 の sweep は、受験者の面に親の行が無いことと、登録者(root の agent)が出ないことを釘にする。

置き換える決定: ADR 0245 決定2・4・5、ADR 0247 決定1・2(root の子を数える判定を対象の答案を数える形に)、ADR 0248
決定1・2、ADR 0253 決定1(出題は親の無い受験者を登録する)、ADR 0263 決定2・3・4・8・10。そのまま残る: ADR 0245 決定1・3、
ADR 0248 決定3、ADR 0251、ADR 0264(視界の「Interview の木」は root と受験者の列挙で、親子を使っていない)、ADR 0266。

## 退けた形

- **木のまま、分岐の列を正本と認める。** 木の規則が増えるたび(兄弟の handoff・abandon の範囲・早期統合復帰の類)Interview の
  例外を1本足し続ける。#2013 を11本目で塞いでも次で割れる。
- **Interview を task でなく記録にし、出題 task と採点 task を持つ。** blocked に触らずに済むが、question・判断ログ・outcome の
  置き場が2 task に割れ、「Interview は root review task」(ADR 0111 決定6、ADR 0248 決定3)を書き換える。
- **受験者を task でない存在にする。** 受験者は worker session の器で、pickup・pin・verb の帰属・event・watchdog・ブランチ・
  handoff・学習器・記憶の視界が全部 task id に掛かる。第2の実体に写し直すことになる。

## 追記(2026-10-16 の grilling、issue #2109 / ADR 0268)

決定1 の「root の下に生えるのは対象であって task ではない」は「対象と付帯子」に改める —— root は本番の review task と同じく、異議由来の
RCA review と人間が名指しで登録する review 子を受ける(ADR 0268 決定5)。受験者が親を持たない線と、受験者の下には question 以外何も
生えない線はそのまま。root を走らせる agent は ADR 0269。
