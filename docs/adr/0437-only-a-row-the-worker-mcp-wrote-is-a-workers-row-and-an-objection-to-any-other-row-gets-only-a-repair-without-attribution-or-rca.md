# worker の行は worker の MCP が書いた行だけで、それ以外の行への異議は帰責も RCA も持たず修理子だけを立てる

**Status 追記: 決定1 の「worker の MCP の扉を通った」は、[ADR 0439](0439-a-worker-mcp-call-is-the-workers-only-with-its-spawns-tally-and-the-tally-never-reaches-the-workers-tools.md) で「その spawn の合札を持つ呼び出し」になる(2026-11-27、issue #3978)** —— 退けた案に書いた扉の封じ込めの隙間は、そこで閉じる。

2026-11-27 の triage と grilling(issue #3974、元は #3936 / #3937)で決定。

異議できる行の書き手は worker だけではない —— 人間は質問への回答と人間が担う task の完了を、盤面の規則は根への告知を書く。
盤面は「異議された行は worker の session の判断か」を1つの事実として持たず、読み手ごとに推し量っていた: self RCA と起草は
書き手が人間かで、学習器・Precedent・判事の入力・流し読みの session の紐づけは event id が session の窓に入るかで。前者は盤面の行を
worker の行と読み、誰も pickup できない self RCA を立てる。後者は書き手を見ず、session の走行中に同じ task へ書かれた worker 以外の行を
その session の判断に数えうる。判事は worker の判断を前提に定義した cause を人間の行にも付けていた。決定はコードの読みに依り、
走らせたものは無い。読み手の表は #3974 に置く。

## 決定

1. **worker の行は、worker の MCP の扉を通って書かれた行だけ。** 事実は記録が既に持つ行の出所で、新しい欄は足さない。
   異議・帰責・学習・Precedent・流し読みの読み手は全員この1つを読み、書き手の名前や窓で個別に判定しない —— 窓の判定は、この事実の上に
   重ねて読む。判定が2通りある限り、片方を直しても漏れが別の書き手で出る。
2. **worker 以外の行への異議は、修理子だけを立て、帰責・RCA(self も auditor も)・起草を持たない。** 判事は初回も第2回も撃たず、
   その異議群は未帰責(ADR 0168)ではなく帰責の対象外である。cause はどれも worker の判断を基準に持ち主を読む —— `capability` はその
   判断の不足、`environment` は判断が妥当だったときの外側の事情(ADR 0213 決定2)—— ので、それ以外の書き手の行に付けても読み手が
   意味を読めない。RCA も仕事を持たない: 人間が自分の行に異議するとき原因は本人で、方向コメントが既にそれを言い、盤面の行の直す先は
   盤面のコードで、RCA が着地させる差分(指示・authority・template)の外にある。修理子は今の規則どおり帰り先があれば立つ。異議の扉は
   書き手を問わず受け付ける —— 異議は観測であり、行の注釈として残る。質問の文脈が誤解を招いて人間の回答が誤った形の異議が観測されたら、
   質問を書いた agent の文面に向けた RCA を問い直す。
3. **停止は範囲の外。** 停止は session に打たれ、行を名指さない(ADR 0310)。「session を誰が走らせたか」の判定はこの決定で変えない。

## 退けた案

- **書き手の session を名乗る新しい欄を events に足す** —— 出所の値が既に同じ区別を持つ。出所の値が意味するのは「worker の MCP の門を
  通った」であって「process が生きていた」ではないが、その隙間は扉の封じ込めの問題で、書き手の判定の問題ではない(#3978)。
- **異議の扉で worker 以外の行を拒む** —— 修理子と行の注釈まで失う。
- **worker 以外の行には常に auditor RCA を立てる** —— 今は cause が RCA に向くときだけ立つので、帰責を外すと異議のたびに Auditor の
  session が走る。直す先が RCA の差分の外にあり、その費用に見合う仕事が無い。
- **worker 以外の行には別の問い方の判事を撃つ** —— 記録された cause を読む読み手(学習器、起草、meta-review)はすべて worker の判断を
  前提に読む。別の語彙を作っても読み手が居ない。

## 他の ADR への影響

- ADR 0115 決定2(異議を束ねる時点で帰責を付ける)は worker の行に狭まる。
- ADR 0168 の未帰責(撃てなかった・失敗した)に、帰責の対象外が並ぶ —— 第2回を待たず、RCA に倒れない。
- ADR 0322 追記(判事の入力の `actor` で人間の行を見分けさせる)は、人間の行が判事に届かなくなるので前提を失う。
