# 盤面の外への書き込みと記録の間の死は、落ちた後の最低線だけを満たす —— fail-closed・決定が読む誤った記録を残さない・出口を名指す

2026-11-22 の grilling(族の根 issue #3515)で決定。盤面は、外への書き込み(checkout の git、出元 repo への push、registry の commit)と盤面
DB の記録を1つの同期区間で書く。await を挟まない区間が防ぐのは交差であって、process の死ではない。この grilling は、死の後で盤面が
自動で収束させる形を2つ設計し、反証で2つとも捨てた。族の件ごとの今の挙動、外への書き込み51件の表、反証の記録は #3515 のコメントに置く。

## 決定

1. **死の後に残る状態に求めるのは落ちた後の最低線の3つで、自動の収束は求めない。** (1) fail-closed であること。(2) 後の決定が読む誤った記録を残さない
   こと。(3) 人間の出口が働き、文面がその出口と原因を正しく名指すこと。この族の頻度はクラッシュの頻度である。
2. **族は機構で3つに分けて読む。** A: 外への書き込みの後に書く event が、死を越える基準の予告に遅れる2冊目の帳簿になる。B: git への
   書き込みが2回あり、基準は ref しか見ない(作業ツリーと index は見ない)。C: 残った行の出口が塞がる。直しは機構ごとでなく、最低線を破る件ごとに置く。
3. **`pr_head_observed` と「外の head」は「盤面の記録に無い head」を指し、誰が push したかを断定しない。** push の後・記録の前に盤面が
   落ちると、盤面自身の push がこの head になる。挙動は変えず、question とその文面が「盤面は push していない」と言わないようにする。
   その PR は無人 merge のキューへ戻らず、以後は人間が merge する。
4. **ローカル着地の答え直しは冪等にする。** タスクブランチが履歴で保護ブランチに含まれていれば、`merge` は何も書かずに、その task を
   持ち込んだ commit を執行として記録する。`hold` はそれを理由に断り、`merge` を名指す —— 載った内容に断念を刻めば、決定が読む誤った記録になる。
   含まれるかは内容(ADR 0105)でなく履歴で判定する —— 別の根が同じ変更を運んでも、その根の着地にはならない(ADR 0289 決定3)。
5. **削除の途中で残った基準の行には、扉を開けず、今の出口を名指す。** 登録の扉は、名前に `workspace_state` の行が残っていれば断る。
   断る文と B9 の文は、「entry を削除の親 commit のとおりに registry へ戻す → 開いていれば Quarantine を受理する → 削除の扉 → 登録し直す」を
   名指す。戻した後は、通常の扉が名前の解決できる状態で守りを通す。
6. **registry と DB が食い違う tier の件は、構造で分かる事実で読む。** 承認の commit が名指す `(question <id>)` が registry にあれば、
   stale ではなく適用済みとして閉じる —— stale と読む2箇所(周期の照合と、答え直しの `stale()`)の両方で。改名の窓の間に tier を
   解決できない agent の提案は照合しない。改名の再実行を名指す文は、agent を解決するときだけに出す。
7. **作業ツリーだけが進んだ checkout は、今どおり人間に回し、文面を正す。** dirty の文は、盤面自身の移動が止まった場合もあると言い、
   比較が畳む前に読んだ予告の目標 sha を名指す。捨てる操作は sparse の pin の下でも木を空にしなければならない(#3614)。

## 退けた形

- **実行中の操作の記録を DB に持ち、書いた本人と起動時の畳みだけが消す** —— 基準の比較(ADR 0351 決定4)と覚えた repo の検査が
  同じ予告を別に畳み、帳簿が2つになる(ADR 0243 が退けた形)。push の成否は remote にしかなく(下の帰結)、読み手が畳むより先に head を
  読んで動く。起動時の畳みは、生き残りの process の検査より前に走る。
- **外への書き込みが自分で名乗る**(head が手元の tip と一致すれば盤面の push、registry の commit の trailer が続きの DB 変更を運ぶ)
  —— 手元の tip を基準と比べる前に読む(ADR 0370 決定1)。後から刻む記録の id が順序を読む判定(断念の解除)を崩す。trailer は偽造できて
  ADR 0373 決定14 を素通りさせる。
- **削除の扉が registry に無い名前の行を終わらせる** —— 名前が解決できないと着地を待つ task の守りがほぼ全件を数え、B9 の Quarantine を
  同じ名前の他の Quarantine と区別できない。

## 帰結

- 限界: `restoreBaseline` の後に死ぬと `baseline_restored` は残らない(読み手は無い。人間は keep-around の値を知らない)。諦めて(ADR 0392)
  タスクブランチが消えた後のローカル着地は、答え直しでも含まれるかを判定できず fail-closed に留まる。
- ADR 0243 の「盤面が死んでも子の push は完走して写しを動かす」は、写しを盤面が push の後に別に書く形(ADR 0052 Status 追記、#2827)
  で偽になった。死の後は、remote に載り写しは旧い値に畳まれる。収束の経路はもう一度 push して治る。
- 実装は #3517 / #3198 / #3199 のコメントと #3614 / #3615 / #3616 の本文の spec。#3516 はこの限界で閉じる。外への書き込みの表で最低線に照らしていない行は #3621 が持つ。見直しで見つかった疑い(「諦める」の記録の順序、削除の後に残る作業台)は #3624 / #3625 が測る。
- 限界: B9 の文は、同じ名前に先に開いた Quarantine の dedupe と、他の名前の Quarantine による最初の撮りの止めで隠れうる。
- 「床」(ADR 0033 / 0038)とは別の語である —— 床は worker の保証と残余の既定を指す。
- Status 追記: ADR 0150 決定1、ADR 0231 決定4、ADR 0243、ADR 0289、ADR 0351 決定5、ADR 0378 決定10、ADR 0387、ADR 0391 帰結、ADR 0394 決定5。

## 追記(2026-11-24 の triage、issue #3635)

決定6 を、stale と読む箇所の列挙から、registry の提案の question を閉じる経路のすべてに当たる性質に改める。列挙は、表の書き口の hook(#3635)、
reject の回答(#3636)、祖先の cancel の3つを落としていた。経路の表は #3635 のコメントに置く。

- **registry の提案の question は、承認の commit を registry に問うてからでないと閉じない。** 周期の照合、approve と reject の回答、表の
  書き口の hook、祖先の cancel(直接 cancel と failure の abandon)のどれで閉じるときも、`(question <id>)` を名指す commit があれば適用済みとして
  閉じる。reject の回答は approve と同じく適用済みの印で返し、tier がもう動いたことを言う —— 却下と刻めば、適用された承認を決定が読む誤った
  記録で閉じる(決定1 の (2))。
- **問えなければ閉じない。** registry の log が読めないとき、照合(周期と表の書き口の hook)はその回は閉じず、回答と cancel は断る。cancel を
  断るのは fail-closed の側で、log が読めないのは registry の clone が壊れたときに限られ、そのとき盤面は registry が読めない停止を既に立てている。
- **祖先の cancel は、扉で範囲の registry の提案に先に問い、適用済みを閉じてから倒す。** 既に起きた registry の変更は計画と一緒に死なない
  —— ADR 0271 決定3 の線(仕事の宛先が親の生死に依らないものだけ残す)と同じ読み。
- **表の書き口の hook が照合するのは表の側の pin(根拠の行・段の順序)だけ。** `observed_event_id` はその pin を崩した表の event を名指す
  欄なので、registry の側の崩れはこの経路では閉じない。hook が見送った表の側の pin は、周期の照合と approve の回答も照合する —— hook だけが
  照合する形のままだと、見送った提案を根拠の崩れたまま approve できる。
- Status 追記: ADR 0150 決定1、ADR 0271 決定3。
