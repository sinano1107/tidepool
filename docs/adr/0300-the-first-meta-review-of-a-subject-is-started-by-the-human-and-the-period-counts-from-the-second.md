# 主題の初回の meta-review は人間が起こし、周期は2回目から数える —— 材料が判断に足るかは人間が測る

2026-10-22 の triage / grilling(issue #2437、出どころは #1880 / ADR 0298 決定9)で決定。ADR 0120 決定2 は周期を「前回の登録からの
間隔の下限」と置いたが、前回の無い初回を書いておらず、code は下限の検査を飛ばして材料1件の次の poll で初回を登録していた。
新しい盤面では、人間が表の行を1つ直した直後に session 0本で routing meta-review が、最初のエントリ1件で memory meta-review が
立ち、後者は leaf 1件から枝の Definition を書いて以後の書き手の INDEX に載る。現状の読みと実測は #2437 / #1880 のコメントに置く。

## 決定

1. **前提: 初回の meta-review は、判断に足る材料が溜まるまで走らない。** 問いは「足る」を何で測るかで、取りうる物差しは時間・量・
   人間の3つしかない。時間(最初の材料から1周期)は、待っても task 1本しか終わっていなければ同じ薄さになるので足りない。量は
   盤面に件数の床がどこにも無く(学習器は「観測の**ある**候補へ」で固定の N と比べない、ADR 0181)、routing は session・memory は
   entry と主題で単位が違い、既定の N に根拠を置けない。残るのは人間で、学習器が shadow のまま人間の承認で初めて効く
   (ADR 0110 決定4)のと同型である。
2. **主題ごとに、初回は人間が起こす。** 周期の登録は、同主題の `meta_review_registered` が1件も無い間は動かない。盤面は人間の面に
   主題ごとの「盤面の始まりからの材料の件数(due が数える集合と同じ述語、ADR 0151)と最初の材料の時刻、初回は未実施」を示し、
   「初回の <主題> meta-review を起こす」扉を置く。扉の門は3つ —— 同主題の登録が無い・材料が1件以上・同主題の未決着が無い
   (ADR 0123 決定3 のとおり未決着の門は手動でも通す)。登録は周期登録と同じ関数で、task は盤面名義のまま(本文は盤面の指示で人間は編集できない、
   ADR 0198 決定4)、人間が起こした事実は同じ種別の `meta_review_registered` event の経路(origin / worker)が運ぶ。event は
   watermark を持つので、窓と due の読みは変えない。初回の窓は盤面の始まりからで、材料は失われない。
3. **2回目以降は今のまま。** 周期の起点は最新の登録(取り消しも含む、ADR 0193 決定2)、窓の起点は完了した最新の登録。初回が
   abandon で取り消されても登録は在るので扉は閉じ、周期が引き継ぐ。扉は「いつでも起こす」口ではない —— 周期 = 間隔の下限
   (ADR 0120)と「入口は周期だけ」(ADR 0123 決定2)を人間が破る口は作らず、ADR 0123 決定2 を改めるのは前回の無い回だけである。

## 退けた案

- **現状維持(初回は材料1件の次の poll)** —— session 1本は安いが、memory の初回が leaf 1件から書く Definition は次の review が
  直すまで書き手全員の置き場の基準になり、routing は session 0〜1本では no_change しか書けない。自律プロセスの最初の判断を
  最も情報の少ない時点に置く形。
- **最初の材料から1周期待つ** —— 落ちたのは量の基準(決定1)であって、ADR 0120 が「寝かせる」案を退けた時刻の理由ではない。
- **起動時刻から1周期** —— 起動の event が無く、初回の前に再起動すると1周期ずつ先送りになる。
- **件数の床(材料2件 = 繰り返しの最小、または人間が置く床)** —— 初回には決定1 の理由で採らない。一般の回の薄さ
  (周期以上の空白の後、材料1件で立つ)は同じ秤に載っていないが、ADR 0120 決定2 そのものの改訂なので別 issue に置く。
- **issue と ADR 0298 が継ぎ当てとして退けた「周期登録の保留」と「今すぐ登録する扉」** —— 2部品を初回の設計として組んだのが
  決定2 であり、継ぎ当てだったのは初回の時点を決めずに足す形の方。

## 帰結

- 一般の回には人間を置かない —— 毎回人間が起こす形は自律の Condensation ループ(ADR 0083 / ADR 0120)を壊す。初回と一般の回の
  非対称はこの理由で残す。
- 学習器の昇格は routing meta-review の提案を経るので、人間が routing の初回を起こすまで始まらない。
- ベンチマーク(ADR 0298)の人間の手順に「主題ごとに初回を起こす」が入る。決定9 の「実運用でも初回は真っ先に動く機能」は偽になる。
- 面の件数は盤面の履歴に比例するので、行を読み込まず数える。
- CONTEXT.md の Meta-review の項とルート review の入口(3つ目: 人間が主題つきで起こす初回)を直す。
