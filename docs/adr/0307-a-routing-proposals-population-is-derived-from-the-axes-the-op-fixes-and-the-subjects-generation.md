# routing の提案の母集団は、op が固定する軸 = 対象の今の値 と、対象の種類の世代から導く —— 表のセルに語を写さない

2026-10-23 の triage / grilling(issue #2542、#2523 / #2524 の族の根)で決定。ADR 0302 の op ごとの表は決定1・2 から導いたものとして
書かれたが、各セルは他の ADR / CONTEXT.md が持つ語を写して言い直したもので、写しは元と別に動く。鍵の列は ADR 0306 で「session の
6 軸から対象が固定する軸を落とす」導出に置き換わり、母集団の列は手書きのまま残った。全行を元と照合したところ、`row` / `add_tier` /
`interview` は元(ADR 0210 決定2・ADR 0200 決定8・ADR 0273 決定7)と一致し、`agent_tier` は「全期間」が元(ADR 0150 決定1)と
0302 決定1 自身の原則(対象の今の世代)の両方に反し、`promote` / `demote` は引用の範囲が ADR 0181 追記 決定1 と決定3 で食い違っていた
(#2523)。照合の表・釘の test・`file:line` は #2542 のコメントに置く。

## 決定

1. **母集団は「op が固定する軸が対象の今の値に等しい本番の session」と「対象の種類の世代」の交わりで、op が持つのは固定する軸の
   集合だけである。** 固定する軸の集合は ADR 0306 決定4 が鍵の導出に使うものと同じ 1 つの宣言で、母集団の述語と組の鍵の両方が
   そこから出る —— op ごとに述語の文も鍵の配列も書かない。値が 1 つでない固定軸(`interview` の走った行は引用した行の集合)は
   母集団を絞るが鍵からは落とさない(ADR 0306 の「6 軸のまま」と同じ)。「本番」の定義(work 側の task の session、受験者でない)は
   ADR 0302 決定1 のまま。
2. **世代は対象の種類ごとに 1 つで、持ち主を名指す。** 行: 走った段 = 行の今の段(ADR 0210 決定2 —— 学習器が数える世代と同じ)。
   agent: 走った段 = agent の今の宣言の段(`source.tier` が agent の session は宣言の段で走る —— ADR 0210 決定1 が spawn に解決した
   段の id を置くので、registry に変更の event が無くても読める)。段: 説明の最後の編集以降(位置だけの編集は数えない、ADR 0302)。
   学習器のフラグ: 最後の変更以降 —— 引用の外(ADR 0181 追記 決定3)だけでなく**引用できる範囲も同じ**で、ADR 0181 追記 決定1 の
   「乖離した shadow 行」はこの範囲に読み替える(#2523)。
3. **ADR 0302 の表の母集団の列は、この導出に置き換わる。** 表は書き換えず Status 追記で指す(鍵の列を ADR 0306 が受けたのと同じ形)。
   ADR 0302 の「触らないもの」(op ごとの分岐が 4 か所に散る形、#2234 / #2491)は変えない。

## 帰結

- `agent_tier` の根拠は agent の今の宣言の段で走った session に限られ、宣言が下がる前の session は理由を名指して拒まれる。固定する
  軸に段が加わるので、ADR 0306 決定4 の導出で `agent_tier` の組の鍵から段が落ちる(#2541 の実装の後に乗せる)。
- `tier_description` の述語は task の要求でなく session の走った段で見る(出所 task なら同じ値)。
- 昇格 / 降格の detail で、引用の件数と引用の外の 1 行の「cited」が同じ範囲を数える。
- 元の定義が動いたとき、表の写しを探す代わりに世代の表の 1 行を見ればよい。

## 退けた案

- **`agent_tier` は全期間のまま(ADR 0302 の表)** —— 「registry に変更の event が無い」は時間で切れない理由で、段で切れない
  理由ではない。`row` を「最後の書き込み以降」でなく「今の段」で切ったのと同じ手が使える。ADR 0150 決定1 の推論「T を実体化した
  行が過剰 ⇒ T の宣言が過剰」は T で走った session にしか立たず、pin も (agent, T) で固定している。
- **昇格 / 降格の引用は全期間のまま、ADR 0302 決定1 の出典を決定3 に直す** —— 同じ detail の中で引用の件数と「cited」の範囲が
  違い、数が合わない。世代の原則から学習器のフラグだけが外れる。
- **`agent_tier` と #2523 を op ごとに個別に起票する**(triage 時の案)—— 決定1 で母集団が 1 つの宣言から出ると決まり、2 つとも
  世代の表の 1 行になった。分けると #2541 の PR の上に 3 本が順に乗る。
- **ADR 0181 追記 決定1 の文を書き直す** —— 決定番号が docs 6 箇所・issue 5 件の引用先。Status 追記で読み替えを指す。
