# Interview の分解は対象の一覧をちょうど1回ずつ覆い、一覧に同じ対象は2つ置けない

2026-10-14 の triage / grilling(issue #1903)で決定。ADR 0199 決定3 は子の pin が「一覧のどれか」であることしか求めて
いなかったので、root が一覧の対象を飛ばしても、同じ対象に2つの子を pin しても盤面は通した。Interview は一度しか分けない
(ADR 0245 決定3)ので、飛ばした対象は測られないまま root が完了し、それを知らせるものが無い。重ねた pin は同じ対象の
答案を2回採点させる。登録の扉も一覧の重複を拒んでいなかった。コードの照合は #1903 のコメントに置く。

## 決定

1. **Interview の decompose は、一覧の各対象にちょうど1つの子を求める。** 足りない対象も、同じ対象への2つ目の子も拒み、
   どの対象が欠けた・重なったかを名指す。走らせる対象を選ぶのは登録の時の人間で(ADR 0199 決定3)、root ではない。
   対象を外す正当な経路は人間の行為として別にある —— 最初から登録しない、断られた対象の「この対象は測らない」
   (ADR 0199 決定4)、pin の子の failure question の abandon(ADR 0245 決定5)。分解で黙って外せる道は、外したことを
   どこにも残さない。
2. **対象の一覧に、4欄一致の同じ対象は2つ置けない。** 登録の扉で拒む。同じ対象を2回走らせても同じ probe・同じセルの
   観測が二重に数えられるだけで、測れることは増えない。pin は4欄で対象を引くので、重複があると2つ目の対象は名指せない。
   retry は登録時の一覧を写す(ADR 0248 決定2)ので、扉で拒めば重複は写されない。
3. **人間の decompose にも同じ検査をかける。** 人間は全権限を持つ worker だが、決定1 の外す経路が人間にはあり、分解で
   外すことを許す理由が無い。

## 退けた案

- **一部を飛ばすのは許し、重複だけ拒む** —— 決定1。飛ばした対象は人間の承認を root が覆したことになる。
- **一覧の重複を黙って束ねる / 許して2回測る** —— 決定2。黙って束ねると、登録した人間の入力が書き換わる。
- **重複を表の UNIQUE 制約で拒む** —— effort の null は UNIQUE では互いに別の値になり、effort を持たない対象の重複を
  拒めない。検査は扉の述語に置く。
