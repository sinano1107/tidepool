# 面接室の Quarantine は開く task ごとに人間が辿れる出口を名指し、読む head が欠けた RCA は表示のたびに導く選択肢への回答で cancel する

2026-11-20 の grilling(issue #3159)で決定。面接室の Quarantine の項の文は、出口として一律に「cancel the task that opens it」を予告していた。
ところが面接室を開く task の多く —— 受験者、完了時レビュー、監査、異議の RCA —— は人間の直接 cancel の範囲の外にある(ADR 0198 /
ADR 0267)。前の3つは root の cancel で倒れるが、RCA は cancel の cascade を生き延びる(ADR 0271)。Quarantine の間は走らないので、
RCA は失敗せず failure question も立たない。そのため、却下の後に出し直した root への異議の RCA が読む旧い出題の head(ADR 0361 決定1 の
Status 追記)が面接室から欠けると、面接室の名前ごと —— root も受験者も —— 止まり、その head を戻す以外の出口が無かった。開く task ごとの
扉の表と `file:line` は #3159 に置く。コードと ADR の読みで決めていて、盤面は走らせていない。

## 決定

1. **項の出口の文は、項の持ち主を倒せる人間の扉から導く。** RCA の項は決定2 の選択肢を名指す。受験者・完了時レビュー・監査の項と面接室
   そのものの項は Interview の root の cancel を名指し、根拠として面接室を読む別の root の項はその root の cancel を名指す。出口の違う
   task の項は1つの文にまとめない。
2. **面接室の Quarantine に、項が落ちた RCA を cancel する回答を足す。** cancel するのは回答の時点で項が落ちている RCA だけで、1つも
   無ければ回答を拒み、拒否文は落ちている他の項を名指す。受験者や root には既に人間が辿れる出口があり、範囲を「項が落ちた開く task
   全部」にすると、1つの回答で Interview 全体が倒れうる。
3. **cancel は回答の受理と同じ transaction で行う。** 項が落ちた RCA の項を外して残りの項を撃ち、すべて通ったときだけ、RCA の cancel と
   解除を一緒に行う。cancel の event の理由には、欠けていた head と答えた Quarantine の question を盤面が書く。
4. **回答で倒す RCA には、直接 cancel と同じ門を当てる。** 倒す範囲に開いた failure question、または別の資源の Quarantine があれば回答を
   拒み、先に答える question を名指す。部分木の行方は、それを握る開いた question の答えだけが決める。いま答えている面接室の Quarantine
   自身は門から除く。
5. **この選択肢は question に保存せず、表示のたびに記録から導いて添える。** 条件は「この面接室を開く未決着の RCA が居る」ことで、表示は
   git を撃たない。添えるときは、その cancel で捨てられる done の work も見せる(ADR 0271 決定4)。ADR 0373 決定2 の「選択肢は常設で、
   場面ごとに出し分けない」は、この選択肢については当たらない。決定2 の理由は「本文と選択肢は最初の登録で固定される」で、表示のたびに
   導くなら、Quarantine の後で立った RCA の出口が消えることもなく、居ない場面で人間に読ませることもない。

## 考えた案

- **H1 なしで RCA を走らせる回答(劣化経路)**: RCA が監査と同じ環境を読むのは、それが判定の材料だからである。読まずに出した帰責は
  記憶や見本の材料を汚しうる。しかも新しい event・pickup の分岐・spawn への注入が要り、起きるのは人間か外部が面接室を壊したとき
  だけ(旧い head は `refs/keep-around` で守られる)なので、見合わない。
- **直接 cancel の範囲に RCA を入れる**: ADR 0198 が RCA を外したのは「規則が要求する入力を黙って抜く」ことを防ぐためで、この場面と
  関係なく扉が広がる。回答への cancel は、欠けた head の観測に対して明示的に選ばれ、記録に残る。
- **`give up the lost refs` に畳む**: ref と commit は残り、tree や blob だけが欠けた場合に出口にならない。
- **RCA の項の失敗では、名前でなく RCA だけを止める**: 欠けた object は面接室の破損の兆候なので、名前で止めるほうが fail-closed で
  ある(ADR 0329 決定4 の Status 追記)。

生きた読み手が居ない面接室の Quarantine が閉じられない件は #3448、`run with an empty room` を同じく導いて出し分ける件は #3449 に分けた。
