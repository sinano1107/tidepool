# task は自分の中身が向かう repo を覚え、根を運ぶ・PR を扱う所でそれを今の宣言と比べ、食い違えばその根だけを止める

2026-11-22 の grilling(issue #3500、族に #3390 / #3584)で決定。削除の扉 → 登録し直し は、path の差し替え(ADR 0373 決定14)と
repo を移す道(ADR 0378 決定9)を兼ねる。PR を開いた done の根は削除の扉を止めず(ADR 0370 決定1 が生き残らせる)、別の repo で
登録し直すと、着地はその根の PR 番号で新しい repo の無関係な PR を読み、決着を旧い根に刻む。新しい repo で同じ番号が振られると、
番号から根を引く読み手が旧い根を返す(どちらも実測、issue #3500 のコメント)。根と repo の結び付きを名前が持ち、名前の値を変える手
(登録の扉・publish の扉・出元 repo の設定・改名・綴り直し・手編集)はどれもそれを壊せる。

## 決定

1. **task は、自分の中身が向かう repo を覚える。** 宣言の repo と `branch` は pickup の門が、pickup が宣言の repo に届いた後で書く。
   出元 repo は、根が最初に `task/<id>` を出元 repo へ push したときに書く —— 守るのは push した内容と PR の head の在りかで、まだ
   何も出していない根を fork の追加・作り直しで止めない。届く前の値(盤面が出られない綴り)は書かない。
2. **2回目以降の pickup と、根を運ぶ・PR を読む・merge する・番号から根を引く所は、その記録を今の宣言と比べる。** 比べ方は
   ADR 0378 決定4。番号から根を引く読み手は、根が記録した repo を鍵に含める(PR は比べて一致した後に開くので、PR の repo は根の
   記録と同じで、別の列に持たない)。記録の無い根は食い違いとして扱う(fail-closed、移行は書かない)。
3. **食い違えば、その根だけを止める。** 両方の repo の id を GitHub に問い(食い違ったときだけ)、同じなら改名として根の記録を
   書き換えて event に残し、続ける。違うか読めなければ、その根の PR 昇格失敗の question を立て、文は記録と宣言の両方を名指す。
   出口は断念(ADR 0225)。workspace の Quarantine にしない —— 宣言は扉を通った正しい値で、壊れているのは根との結び付きであり、
   名前で始まる新しい作業まで止める理由が無い。
4. **publish の扉は、その名前の task の記録を purely-local から新しい repo へ書き換える。** 同じ中身が repo を得るだけなので、
   覚えた repo を書く await の無い区間(ADR 0378 決定10)の中で書き、巻き戻しも一緒に戻す。
5. **着地の最初の撮りも、pickup の開く前の項を通す。** 最初に触れる4つの入口のうち着地だけが外れていた(issue #3390)。登録の後に
   名前の場所で origin を向け替える形は、決定2 の比較では塞がらない(宣言は変わっていない)。

## 退けた形

- **同じ名前の登録し直しを前の登録の続きとし、名前の repo を削除をまたいで残して登録の扉で拒む** —— 一度この形で書いた。名前の
  値を変える手ごとに門か例外が要り(出元 repo の足す・差し替える・外す、登録し直しでの出元 repo の写し、改名、GitHub の外の ssh の
  綴り直し、`branch`)、grilling の2ラウンドで5つ足した。書き手が1つの task の記録に移した。
- **削除の扉が PR を開いた根も数えて拒む** —— GitHub で閉じられた PR の根は、内容が来なければ盤面が GitHub を読まず決着が刻まれ
  ないので、扉を永久に止める。帯域外で足した registry の行も塞がらない。

## 帰結

- 同じ名前は別の repo にも登録し直せる(ADR 0378 決定9 は真のまま)。開いた PR を持つ根はそこで止まり、人間が断念する。
- ADR 0378 決定6(名前の覚えた repo による手編集の門)と出元 repo の覚えた値は変えない。task の記録はそれに重ねる根ごとの床である。
- ADR 0383 決定2 の開く前の項は、着地の最初の撮りに広がる(Status 追記を置いた)。
- 改名で自分の PR の探索が取りこぼす疑い(#3578)は、根を運ぶ前の探索の話で、この決定に依らない。
