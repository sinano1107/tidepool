# 表の行は具体 id だけで、学習器は行に完全一致で当たり、薄い先頭は却下1件では離れない

2026-10-01 の triage / grilling(issue #1245)で決定。学習器のセルは観測された具体 id で持つが、表の行に当てる照合は部分一致
だったので、alias の行(anthropic の `sonnet` / `opus` / `fable`)には、その alias が指してきた全世代の実績が合算されていた。
CLI 更新で alias が前進すると、新しい世代は前の世代の受理 / 却下を引き継いで始まり、Interview で新しい世代を測っても outcome は
同じ行に混ざる —— ADR 0181 決定3 の「Interview 1件で新しい世代へ移る」は、anthropic では移る先が無かった。照合の読みと実測は
#1245 のコメントに置く。

## 決定

1. **表の行は具体 id だけにする。** 行を書く扉(settings タブ / 管理MCP)が、anthropic の adapter が持つ alias の拒否一覧で
   拒み、種の anthropic の行も具体 id で配る。行は「その model はそのティアの品質を満たす」という分類(ADR 0114 決定2)で、
   alias の行は誰も分類していない世代に分類と価格を黙って付ける。alias を選んだ理由は種の手入れが要らないことだけだった。
   拒否一覧は ADR 0005 が退けた許可一覧と違い、古くなっても正当な新モデルを拒まない —— 漏れた alias は通るだけである。
2. **世代の前進は人間の表の編集である。** 新しい世代は新しい行として入り、「人間が足した行」として Interview の発火事象に
   なる(ADR 0110 決定4)。世代を検知する機構は足さない。
3. **学習器のセルは pin の綴りで持ち、行との照合は完全一致にする。** 行が具体 id なら pin が世代を名指すので、使用量の内訳から
   id を引き当てる必要が無くなり、内訳が読めない session も世代を失わない。部分一致のままだと `claude-opus-5` の行が
   `claude-opus-5-5` の観測を拾い、同じ合算が綴りの前方一致で残る。拒否一覧から漏れた alias の行は、pin の綴りのまま自分の
   行にだけ当たる。Throttle の窓は系列単位の枠なので部分一致のまま —— 同じ式を2つの意味に使っていたのを分ける。
4. **先頭の観測が移る先より少ないあいだは、却下数で比べる。** 先頭が残りを全部受理しても追いつけないときだけ離れる、という
   規則で、定数を持たない。先頭の観測が移る先以上になれば事後平均の比較に戻り、薄い候補へ移る側(ADR 0181 決定3)は
   変えない。決定1 で行は必ず薄く始まる。事後平均だけだと、新しい先頭は却下1件で実績の長い行へ移り、離れた行には本番の
   観測が来ず、戻るには相手の件数に見合う連続受理が要る —— ADR 0181 決定2 の「人間が先頭に置いた行を旧い行へ戻さない」が
   却下1件で破れていた。却下数で比べれば、離れたあとも移った先の却下が並べば戻る。

## 帰結

- 種の anthropic の行に、openai と同じ世代交代ごとの手入れが要る。退役した id の行の扱いは #1249。
- 本当に劣化した新しい世代から離れるのは遅くなる: 移る先の却下が多いほど、先頭はその数まで走る。昇格前は表の先頭が
  無条件に走っているので、それより悪くはならない。
- 盤面自身の呼び出し(下書き・翻訳・auth probe)は表を通らず、alias のまま残る(#1248)。

## 退けた案

- **alias の行の実績を、最後に観測された具体 id の世代に絞る** —— 盤面は alias の指す先を spawn 前に知れないので1 session
  遅れ、内訳が読めない session をどの世代に数えるかの推定が要る。分類と価格が黙って付く点も残る。
- **前の世代の実績を弱い事前分布として引き継ぐ** —— 割引の強さは ADR 0110 がノブにしないとした定数である。
- **離れた行へ本番の観測を送り続ける(探索)** —— 割合か乱数が要り、劣ると見ている設定に本番を賭ける。
- **行の綴りと観測された id の食い違いで alias を見つける** —— 一覧は要らないが、1 session 走ってからしか分からない。
- **セルを観測された id のまま完全一致にする** —— 漏れた alias の行に観測が一切当たらず、未観測の先頭として走り続ける。
