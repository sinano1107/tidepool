# 下書きの Board call は表の行で走り、CLI を観測する呼び出しは alias のまま

2026-10-02 の triage / grilling(issue #1248)で決定。ADR 0182 で表の行は具体 id だけになったが、盤面自身の呼び出しは表を
通らずにコードへ alias を直書きしていた —— 下書き `sonnet`、表示時翻訳・認証 probe・skill 列挙 `haiku`。分類と学習器のセル
という ADR 0182 の理由はこれらに当たらないが、「CLI 更新で走るモデルが黙って変わる」は同じである。同じ一発呼び出しの道具を
使う振り返り Board call は、すでに表の行で走っていた(ADR 0111 追記4)。呼び出しごとの現状は #1248 のコメントに置く。

## 決定

1. **AI 下書きは表の行で走る。** 行は `anthropic` × `economy` の最安で、ティアはコードに固定する。その行の model と effort を
   そのまま使い、effort だけを呼び出し側で上書きしない —— 行は (model, effort) の組の分類で、片方だけ借りると settings
   タブでの effort の編集が下書きに効かない。世代の前進は ADR 0182 決定2 の表の編集1か所にまとまる。ティアを盤面設定に
   出さないのは、#1248 が直したいのは世代が黙って前進することだけで、ティアを選びたい要求は出ていないからである。
   振り返り Board call の欄を共有しないのは、あの欄が裁く側と起草する側を揃えるためのもので、下書きは別の用途だからである。
2. **行が無い・窓が閉じているときは、下書きできないと返す。** 振り返り Board call と同じく理由を付け、別のモデルへ fallback
   しない。表の穴は事実である(ADR 0114 決定3)。
3. **CLI の状態を観測する呼び出し(認証 probe・skill 列挙)は alias のまま残す。** 応答の中身を使わないので、走るモデルが前進
   しても観測の意味は変わらない。具体 id にすると得るものが無く、id が断られた日から認証 probe は `unknown` を返し続け、
   Provider 認証の Quarantine を外せなくなる(#466 / #737 と同じ形)。alias は指す先が必ず存在する。
4. **表示時翻訳は alias `haiku` のまま残し、#1346 と #456 の着地で見直す。** 表から引くと economy の行になり、表示のたびに
   走る呼び出しの単価と遅延が上がる。表に haiku の行を足すと worker の候補になる(ADR 0114 決定5)。コードに具体 id を
   置くと、表とは別の手入れ場所ができ、断られても気づけない故障が足される —— 行の拒否の証拠は worker の spawn からしか
   取らない(ADR 0184 決定3)。翻訳に合う帯の行(#1346)か、Codex の廉価なモデルで翻訳する道(#456)ができれば、表から
   引ける。

## 帰結

- 下書きは振り返り Board call と同じく、Quarantine 中の行を見たまま撃ちうる。表を直に読む読み手の扱いは #1261 で決める。
- 下書きに `high` の effort が乗り、人間が待つ呼び出しが遅くなりうる。測ってはいない。
- 翻訳は Haiku の世代交代に黙って付いていく。翻訳の質は表示のたびに人間の目に入るので、前進は気づかれずには済まない。

## 退けた案

- **下書きにコードで具体 id の定数を置く** —— 手入れの場所が表とコードのリリースの2か所に分かれる。
- **翻訳を表の economy の行で走らせる** —— 決定4。haiku 4.5 の alias から離れられるが、#1346 / #456 の着地でもう一度動かす
  ことになる。
