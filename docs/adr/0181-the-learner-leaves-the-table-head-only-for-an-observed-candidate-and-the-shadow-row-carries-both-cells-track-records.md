# 学習器が表の先頭を離れるのは観測のある候補へだけで、shadow 行は両セルの実績を運ぶ

**Status 追記: 決定4 の「同じセルの観測」は ADR 0210 決定4 で「同じセルの、同じ段の観測」に読み替え** —— Interview の対象を段 T で測った結果は、T に行があるときだけ数えられる。episode は走った段を持つ(ADR 0210 決定1)。

**Status 追記: 決定3 は ADR 0182 決定4 で先頭が薄い場合だけ変わった** —— 先頭の観測が移る先より少ないあいだは却下数で比べる。薄い候補へ移る側と、先頭の観測が移る先以上のときの事後平均の比較はそのまま。

2026-10-01 の triage / grilling(issue #1243)で決定。#1239 の grilling で、昇格前の shadow の乖離が「表の先頭が失敗した」
ことしか示さないと分かった。原因は推薦の規則にあった: 全候補が受理1件分の疑似観測(平均 1.0)で始まるので、表は同点の
ときの並び順としてしか効かず、先頭に却下が1件付くと一度も走っていない候補へ推薦が移る(100 受理 / 1 却下でも)。昇格後は
その推薦が実際に走る。ADR 0110 決定4 の「昇格後もデータの無いセルでは表と一致する」は、どの候補にも観測が無いときにしか
成り立っていなかった。再現と候補の組み立ての調査は #1243 のコメントに置く。

## 決定

1. **学習器は未観測の候補へ移らない。** 先頭を離れるのは、先頭と移る先の両方に観測があり、移る先が比較で上のときだけ。
   未観測のセルを最初に走らせるのは学習器ではなく、Interview・先頭が除外された pickup・人間の表の編集である。昇格の
   承認 question に人間が答えるには推薦側のセルの実績が要り、未観測へ移る規則ではそれを昇格前に得る手段が無く、昇格が
   「試してみる許可」になる。
2. **未観測の先頭はそのまま走る。** 人間が先頭に置いた新しい行を、学習器が観測のある旧い行へ戻さない。昇格の前後で、
   同じ表の編集が同じ挙動になる。その行が Interview より先に本番で走ることは表の側の問いで、ここでは決めない(#1246)。
3. **観測のある候補どうしの比較は事後平均のまま、観測の薄さを比較に入れない。** 薄い観測で移れることが、Interview 1件で
   新しい世代へ移る経路になる。昇格後に移った先で却下が付けば戻る。旧い行が無傷で同点のときは表の並びのままで、直すのは
   人間である。
4. **Interview の子の outcome は同じセルの観測に数え、種別は episode に残す。** 数えなければ、決定1 が未観測のセルを
   埋める経路として名指した Interview が推薦に届かない。probe は rubric で採点されるので受理の基準が統合点レビューと
   揃わないが、読み手は種別で割って読める。
5. **shadow 行は推薦したセルと走ったセルの、その pickup 時点の実績と、除外後の候補数を持つ。** 昇格の前後とも材料の節に
   出す(ADR 0180 追記の線 —— 昇格 / 降格の判断で必ず読むもの)。決定3 が薄い観測での移動を許す歯止めは、「2/2 対
   101/102」が meta-review と人間に見えることである。候補が1行の pickup は推薦が必ず表と一致するので、節は全行数と
   候補が2行以上あった行数を並べる。
6. **昇格の根拠は推薦したセルの実績に置く。** 昇格前に推薦と実際が分かれた行の outcome は走った側(表)の結果で、
   推薦した設定の結果ではない —— ADR 0150 決定3 の読み物の定義は変えず、purpose がそこから許す推論を直す。昇格後の
   降格の読み物(表と分かれた episode の outcome)は、走ったのが学習器の選択なので変えない。

## 退けた案

- **未観測の候補へ移ってよい(事前分布の強さだけ直す)** —— 候補は要求ティアの行に限られるので代金は ADR 0110 が退けた
  「一様事前分布」より小さいが、決定1 のとおり昇格前に根拠が得られない。
- **観測数を比較に入れる(信頼下限など)** —— 「何件で十分か」の定数は ADR 0110 がノブにしないとした事前分布の強さで、
  新しい世代へ移るのも遅れる。
- **先頭が未観測なら観測のある候補を優先する** —— 決定2。
- **Interview の outcome は読み物だけにする** —— 決定4。
- **候補が1行の pickup に shadow 行を書かない** —— 選ぶ余地が無かった pickup の割合が読めなくなる。
