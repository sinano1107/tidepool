# memory meta-review のエントリの項目は、どの出所でも鎖の末尾が無効化されていないものだけ —— 窓の中の無効化と人間の回答は読まれるが、行は強制しない

2026-10-20 の triage / grilling(issue #2324、元 #2306 の /code-review)で決定。memory meta-review の判断を要する項目(ADR 0278 決定5)の
うち、窓で決着した提案が名指すエントリ・cause `memory` の異議つき判断が名指すエントリ・窓の店の変更は、本文が同じ鎖の末尾が無効化済みでも
項目に載っていた —— 前の review の consolidate を人間が承認して superseded になった replaces、approve の提案を reject されて `rejected` に
なった candidate、異議が名指した後に人間が引退させた Knowledge。memory meta-review の verb(fold / move / invalidate / propose)はどれも
無効化済みの id を拒み、restore は memory_repair と人間の面にしかないので、これらへの `left_as_is` は判断ではなく強制された値(ADR 0278
追記5 の routing の行の無いセル、ADR 0282 決定3 の盤面全体の定義しか届かない枝、ADR 0280 の「値は何もない側だけ」と同じ線)。ADR 0284 は
枝の側の生死を決め、エントリの側をこの issue に預けていた。同じ道具で、材料を組んでから記録するまでの間の無効化に偽の判断の行が書かれること
(#2311)も再現した。実測(`file:line`)と場面の表は #2324 のコメントに置く。

## 決定

1. **エントリの項目は、どの出所でも鎖の末尾が無効化されていないエントリだけ。** 窓で起草された candidate(生きている一覧から引くので既に
   そう)、窓で決着した提案が名指す candidate / 置き換え / 失効の対象、cause `memory` の異議つき判断が名指すエントリ、窓の店の変更、異議
   された判断の行が名指すエントリ(ADR 0279 決定5、既にそう)の5つの出所すべてで同じ述語。項目の生死は、エントリの側も枝の側(ADR 0284)も
   「届く verb がある対象か」で引く。無効化の事実と人間の回答(reject / defer の comment)は Store changes と Settled proposals の部分にその
   まま載り、読まれる —— 行を強制しないだけ。畳みの後継は、窓で変わっていなければ項目にしない —— 生きていて読み手がいつでも行為でき、
   読み手の無い派生の項目を足さない。
2. **完了の「記録の後の誰かの無効化」の集合は要らない。** 完了時の再計算(ADR 0278 追記4 の「今も項目であるもの」)が鎖の末尾の無効化済みを
   落とすので、いつ無効化されたか —— 窓の中、材料を組んでから記録するまで(#2311)、記録の後 —— を問わず、注入済みの項目への値は受け取って
   何も記録しない。routing の `actedSince` に対応する集合が memory に無いのは、memory では他者の行為がすべて対象の存在か鍵を変える
   (引退・畳み → 消える、移動・復元 → 末尾が変わる、candidate の承認 → candidate でなくなる、定義 → 枝の項目が消える)ので再計算が行為を
   写すから —— routing では行を書き換えても行は同じ鍵で残る。

## 退けた案

- **出所で分ける** —— 決着した提案と店の変更は「人間の回答 / 変更を読ませる」項目として無効化済みでも残し、cause memory の異議の対象だけ
  生きているものに絞る。読ませるのは材料の部分の仕事で、項目は値を要求する側。届かない対象に値を書かせる理由にならない。
- **畳みの後継を項目にする** —— 後継は生きていて読み手が行為でき、「後継に何かすべきか」は項目の無い判断として読み手に残る。派生の鍵を足すと
  同じ後継へ複数の replaces から項目が重なる。
- **#2311 を記録に組んだ時点の watermark で切る** —— 再計算が落とすので境は要らない。

## 帰結

- 追記する ADR: 0278 決定5・追記4、0284 末尾。
- 反転する釘は3本(注入の前に無効化された店の変更は unjudged、reject された candidate が項目に載る・記録の items に載る)、setup の修正が1本。
- #2311 は同じ門の同じ直しで閉じる。
