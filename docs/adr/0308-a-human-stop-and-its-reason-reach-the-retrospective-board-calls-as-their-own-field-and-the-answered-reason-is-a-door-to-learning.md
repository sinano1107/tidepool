# 人間の停止と理由は振り返りの Board call に自分の欄で届き、判断ログには混ぜない —— 理由の回答は学習の材料であり扉でもある

2026-10-25 の triage → grilling(issue #2549、#2537 の spec レビューから派生)で決定。ADR 0305 決定2 は「X の history を読むものすべて
(次の session の briefing・`get_current_task`・meta-review・記憶・WebUI)」が停止の行の隣に理由を読むと書いたが、前3者 + WebUI は
history の読み口(#2537 で実装)を通る一方、meta-review と記憶は task の history を読む経路を持たず、記憶の側は帰責・起草の Board call の
入力 `decision_log` と記憶 case の描画がどちらも**判断ログ**(`decision_logged` / 完了 / 前提の破綻 / 記憶の書き込み)に由来する。
列が「history の読み手」と「判断ログの読み手」を1語で束ねていた。判断ログには session を終わらせた事実(cap 中断・watchdog kill)が
一度も入っておらず、人間の停止だけを例外にする理由は無い。一方で ADR 0305 は理由を「後の学習の材料」と呼び、RCA 子は親の history
で停止の行を読めるのに、RCA を立てるかを決める帰責の判事だけが読めない非対称があった。実測と `file:line` は #2549 のコメントに置く。

## 決定

1. **帰責・起草の `decision_log` は worker の判断のまま。停止と理由は Board call の入力に自分の欄で届く。** 欄は異議されたエントリと
   同じ session 窓(spawn から exit まで)の `session_stopped_by_human` から組み、停止の事実と理由(ADR 0305 の読み口1つ: event の reason
   → 理由 question の答え → 未回答)を持つ。停止が無ければ欄は無い。帰責の初回・第2回と Behavior 起草は同じ入力型なので全部に届く。
   出口(failure question / 停止承認付き cancel)は問わない —— 同じ event で、異議は session 単位で集まる。prompt は欄を人間の証言と
   名乗らせ、「要らなくなった」類の理由は cause に使わない。ADR 0115 決定2 の入力(エントリ・steering・当時の decision log)に1語足す。
2. **理由は生で解き、cutoff は停止 event に掛けない。** 第2回の帰責が当時の decision log を初回の切れ目で読む線(#1572)は worker の
   日誌の当時性を守るもので、人間の証言はその対象ではない —— steering の id を釘付けするのは異議群の定義のためで当時性のためではないのと
   同じ。初回で未回答だった理由を第2回が読むのは、答えを捨てるより良い。停止 event は最後の判断行より後に積まれるので切れ目では落ちる
   が、session 窓で引くので `before` に依らない。
3. **記憶 case の描画は判事が読んだものを描く。** 出所が帰責 event で、その入力に停止があったなら case に停止の行(理由つき)を足す ——
   「帰責が入力に使った steering だけ」(#958、ADR 0153 決定3)と同じ規則。
4. **理由の回答は学習の材料であり、扉でもある。扉の機構は別に決める(#2553)。** ADR 0083 決定7「学習の入力は異議だけ」は人間の停止より
   前の決定で、「人間が worker の挙動を shortfall と判断して止めた」事象を想定していない。理由は必ず入る(ADR 0212)ので、異議が無くても
   その回答から学習が発火すべきである。今の第1段は全部「異議されたエントリ」を起点に組まれており(ADR 0115 決定1 の単位、ADR 0120
   決定1 の門)、session を単位にする帰責と名指しの形は別の主題なので、本 ADR は前提だけを置く。決定1 の欄はその機構でも再利用される。
5. **ADR 0305 決定2 の読み手の列を読み直す**: 「history の読み手(briefing・`get_current_task`・WebUI)+ 振り返りの Board call(自分の欄)
   + 記憶 case」。meta-review は列から外す —— 異議された判断行と店の変化を材料にし、停止を読む経路も読む理由も無い。

## 退けた形

- **`decision_log` に停止の行を足す(history 側に揃える)**: 人間の文を worker の日誌に混ぜ、CONTEXT.md「Decision log」(人間の回答は載らない)
  と ADR 0115 決定2 の語を動かす。`HUMAN_FACING_KINDS` は流し読み・未読数・異議対象・wire contract が共有し、広げると面が全部変わる。
- **渡さず RCA 子の history 経由に任せる(欠陥でないと決着)**: 判事が部下の RCA より少ない材料で RCA の要否を決める非対称が残る。
- **理由の答えも cutoff で切る**: 読み口が2つになり、人間が答えた理由を第2回が捨てる。
- **扉は異議のまま(停止は材料だけ)**: 理由を答えた人間に、さらに原因のエントリへの異議を要求する。注意予算を使う(ADR 0115 が退けた線)。
