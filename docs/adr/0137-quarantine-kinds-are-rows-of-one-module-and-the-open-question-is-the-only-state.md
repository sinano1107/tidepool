# quarantine の種類は1つの module の行であり、開いた確認型 question が唯一の状態である

2026-09-21 の grilling(issue #661)で決定。quarantine の機構を使う種類は7つある —— 用語集の資源5種、盤面全体の
封じ込め、そして機構だけを借りる落ちた後始末(ADR 0112 —— 資源ではない、という用語集の線はそのまま)。種類ごとの差 —— 列・散文・解除の門の検査・
受理後の処理・盤面全体の停止への所属・どのタスクを止めるか —— が、立てる側7ファイルと読む側6箇所に手で綴られていた。
1種類足すと8〜9箇所の編集になる。ADR 0068 根拠1 と ADR 0102 決定10 が繰り返し置いた受入基準「増えるのは列挙の1行」は
読み口にしか届いていなかった(ADR 0068 決定5 が自分の範囲を列挙の共有に絞ったためで、未実装ではなく範囲外だった)。
既存の重複の整理なので痛みの観測は待たない。実測と実装の綴りは issue #661 に置く。

## 決定

1. **種類の表は用語集「Quarantine」を名乗る1つの module が持つ。** 行が持つのは、開いているかの問い・散文つきの
   登録・解除の門の検査・受理後の処理・盤面全体の停止への所属。**いつ立てるかは呼び出し側に残る** —— 生きた検査の
   位置と順序は ADR 0008 / 0030 / 0052 が根拠を持ち、ADR 0068 決定5 が「今の位置に残る」と決めた線をこの ADR は
   開け直さない。

2. **種類を運ぶ列は `(kind, value)` の2本にする。** 種類ごとの列を残すと表の行が列名を属性に持ち、1種類足すたびに
   DDL・型・INSERT が動く。盤面全体の種類は value を持たないか、資源でないもの(落ちた後始末のタスク)を運ぶ。

3. **状態は開いた確認型 question の存在だけが持つ。** workspace と agent 名だけが `needs_human` のフラグと question の
   両方で同じ事実を持っていた。食い違えば(question は回答済み、フラグは立ったまま)人間に見える修理手段が無くなる
   形であり、受理後の処理と pickup 述語に種類ごとの別綴りを生んでいた唯一の実質差でもある。

4. **解除の記録は種類を問わない1種の event にする。** 再発火の記録(`quarantine_refired`)が既にそうであり、対を揃える。

5. **解除の門は、検査できない盤面では回答を拒む。** 「確認を鵜呑みにせず検証してから受理する」が Quarantine の定義で
   ある。検査の口が渡されていなければ黙って受理する種類が2つあったが、それは定義の穴だった。

6. **資源単位の種類が「どのタスクを止めるか」は行の属性である。** pickup 述語・直接 cancel の門・pickup から外す
   assignee の集合が同じ行から導出される(ADR 0102 決定8 の線)。registry を読む写像は合成 root から渡す(ADR 0041)。

## 退けた案

- **立てる契機まで module が持つ** —— 契機は2形に割れる(検査を撃って立てるもの / 失敗地点から呼ばれるもの)。
  1形に揃えるには検査の位置を表の属性にするしかなく、決定1 が残した線を開け直すことになる。
- **列を据え置き、表だけ足す** —— 編集箇所は減るが「1行」には届かない。migration を書かない今が最も安い。
- **着地の question(merge / local merge / PR 昇格失敗)を同じ表に載せる** —— あれは確認型ではなく選択を求める
  question で、共有しているのはタスク登録の interface そのものである。族をまたぐと module が名前を失う。
- **合成 root から下の転送層(issue #667)を先に決める** —— この ADR は門の検査の口を種類ごとの別々の欄から
  1つの map に減らす。数が減ってから運び方を測るほうが、測り直しが無い。

## Consequences

- 落ちた後始末の確認は実装上は種類単位で1枚だったが、鍵が `(kind, value)` に揃うのでタスクごとに1枚になる
  (ADR 0112 決定2 の「1件につき確認は最大1枚」に実装が揃う —— 改訂ではない)。2件目の
  後始末が落ちたとき、その再実行が誰の持ち物でもなくなる形が消える。
- `agent_state` は `needs_human` しか持たないので表ごと消える。
