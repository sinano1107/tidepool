# 人間は盤面が登録した root を直接 cancel できるが、編集はできず、盤面名義の付帯子には直接 cancel も届かない

2026-10-05 の grilling(issue #1348、発端は #1237)で決定。#130 は Edit と直接 cancel の範囲を「人間が登録した task」に
引いた。範囲から外す理由として挙がったのは agent の分解の子だけだった(子は分解判断の一部で、不満は異議 → 修理が担う)。
盤面が登録する task は、その理由に当たらないまま同じ判定(登録者が `human` か)で外れていた。そのため、周期の meta-review を
止める経路は、失敗を待って failure question に abandon と答えることしかなかった。

## 決定

1. **直接 cancel の範囲は「人間が登録した task、または盤面が登録した root(question を除く)」である。** 今この root に当たるのは
   meta-review だけである。盤面の周期規則には、#130 が守った「判断の主」がいない。meta-review に異議を打っても修理されるのは
   成果のほうで、登録を止める経路にはならない。状態の線(未決着・実行中でない)と門(`assertNoGatingQuestion`)は今のまま。
   取り消した後のことは ADR 0193 が経路を問わず決めている(この回を飛ばし、材料は次の回が読む)。開いている提案 question は、
   abandon と同じく道連れになる。
2. **盤面名義の question は範囲に入れない。** question は回答で決着するものであり、回答が唯一の門である(CONTEXT.md Cancel)。
   root の question(CLI 認証期限の警告など)も同じく外れる。
3. **盤面名義の付帯子(完了時レビュー・RCA review)は範囲に入れない。** どちらも規則が要求する入力である。cancelled も決着に
   数えるので、直接 cancel はそれを黙って抜く。完了時レビューを抜けば、その root はレビュー無しで着地する(ADR 0111 / 0092)。
   RCA review を抜けば、findings の無いまま第2回の帰責へ進む(ADR 0115 決定3)。盤面が試して失敗した後なら、abandon で
   取り消せる。
4. **Edit の範囲は広げない。** Edit と直接 cancel の門は2本に分かれる。meta-review の title / purpose は盤面自身の指示文で、
   verb の手順や昇格の規則を運んでいる。人間が書き換えると、盤面名義の task が人間の文で動く。名義から読む判定(注入 query の
   英訳、ADR 0194 決定6)は、その文を見落とす。#130 の Edit は「人間が自分の登録の未消費の値を直す」ためのもので、盤面の
   登録には当たらない。中身に不満があるときは、取り消して次の回に任せる。

## 帰結

- 人間は meta-review を登録できない(ADR 0123)が、取り消すことはできる。これは見落としではない。登録は規則の外に回を
  1つ足す行為で、取り消しはその回を飛ばす行為にすぎない。周期の起点は、取り消された登録からも数える(ADR 0193 決定2)。
- 「人間が登録した task」の判定は、Edit の範囲としてだけ残る。

## 退けた案

- **盤面名義の question 以外をすべて範囲に入れる(人間は全権限を持つ)** —— 付帯子が範囲に入り、規則が要求する入力を、
  盤面が試す前に飛ばす扉が開く。
- **Edit も同じ線で開く(門を1本のまま広げる)** —— 決定4 の理由で退けた。
