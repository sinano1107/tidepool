# 正準テキストは英語、翻訳は表示時の導出

UI を日本語で読めるようにするにあたり、エージェントに日本語で直接出力させる案(system prompt での言語指示)を退け、記録される正準テキストは常に英語のまま、日本語化はすべて表示層の導出として実装すると決めた(2026-07-13 の grilling)。

根拠: tidepool では「人間向けに見える出力」がほぼすべて後段でエージェントの入力になる — meta-review はログ全体を読み、Auditor の独立レビューは成果物と判断ログを読み、handoff doc は統合復帰セッションが消費し、question の選択肢は選ばれた回答としてエージェントのコンテキストに還流する。エージェント消費テキストは英語という既存の不変条件(`src/tasks.ts` 冒頭に明文化)を保つには、正準を日本語にする余地がそもそもない。また「保存値に焼き込まず表示の瞬間に解決する」という盤面の一貫した導出哲学(blocked / held / workspace 帰属と同型)にも一致する。

退けた代替案: system prompt への出力言語指示は、将来の出力の言語切替こそ1行で済むが、過去の不滅の記録が出力時の言語で固定され、レビュー機構が読む記録の言語が人間の表示言語設定に従属してしまう。

精密化(同日の追記): 「英語」の不変条件が覆うのは**地の文(scaffolding)** — 盤面とエージェント自身が発するテキスト(system prompt、tool 記述、handoff の見出し、エージェントの記録) — のみ。**人間が書いたペイロード**(登録した title / purpose / 完了基準、question への自由記述回答、異議の steering、scratchpad)は書かれた言語のまま保存し、翻訳も英訳正規化もしない — 入力時に英訳して焼き込むと、異議やレビューが読む人間の意図の一次資料が機械翻訳になり、記録は不滅・無改変の哲学に反する(エージェントは日本語ペイロードをそのまま読める)。registry の識別子(workspace 名・agent 名)は機械照合に使われるため従来どおり英数字。帰結として、人間登録の日本語 title とエージェント登録の英語 title が Board / Queue 上で混在することは許容する。
