# issue つきの task は登録で issue を読んだ repo を記録し、issue はその記録が今の宣言と一致するときだけ読む

2026-11-27 の triage と grilling(issue #3885)で決定。

issue つきの task は issue を番号だけで持ち、repo の半分は workspace の名前で、読むたびに今の宣言から引いていた(ADR 0016 の
「workspace の焼き込み」)。名前の宣言の repo は削除の扉 → 登録し直しでだけ変わる(ADR 0378 決定6・9)が、完了 task は削除を
またいで名前に残る(ADR 0421 の帰結)。登録し直した後、残った task の issue を読むと新しい repo の同じ番号の無関係な issue を
読み、画面に出し、その下に立つ子の worker の文面に入れる。ADR 0399 が PR について断った代わりの鍵(根の repo の代わりに今の名前の
値)の issue 版である。読みの表は #3885 に置く。決定はコードと ADR の読みに依り、走らせたものは無い。

## 決定

1. **issue つきの task は、登録の扉が issue を読めたときに、読んだ repo を1回だけ記録し、上書きしない。** 記録するのは読んだ時点の
   repo で、書く時点で名前を引き直さない —— 読みから書き込みまでの await の間に名前が登録し直されても、記録は事実のままである。
   宣言の repo の記録(ADR 0399 決定1)とは別の記録である —— 書く時点も意味も違う。登録の扉は ADR 0399 決定1 の「届いたとき」で
   ある。
2. **issue を番号で読む口は、どれも記録を今の宣言と比べ、食い違えば読まない。** 比べ方は ADR 0378 決定4 の綴りである。記録が
   無ければ読まない(fail-closed、移行は書かない)。網の行き先は宣言の repo からだけ決めるので(ADR 0378 決定1)、記録の repo から
   読み直すことはしない。
3. **読まなかった親の issue は、子に「読めない」状態として渡し、子は止めない。** 親の issue が見つからないときと同じ形である
   (ADR 0321 決定3)。子が本文を要るかを盤面は見分けられず、RCA は本文を transcript の記録から読む(ADR 0321 決定1)。
4. **表示は、読まなかった参照を記録の repo と番号で見せる。** 人間は GitHub でその issue を開ける。

## 退けた形

- **削除の扉が名前の下の全 task に「登録が削除された」を書き、その task の issue を読まない** —— path を移すだけの登録し直し
  (ADR 0373 決定14)でも旧い task の issue が読めなくなる。記録の repo が一致すれば読んでよい。
- **登録ごとの識別子を task の作成時に刻む** —— task を作る経路のすべてが書き手になる。宣言の repo が変わるのは削除の扉を通る
  ときだけで、issue の repo の記録で足りる。
- **読む口ごとに宣言の repo の記録(`declared_repo`)と比べる** —— その記録は pickup で書かれ、pickup の前に cancel された task は
  持たない。issue の同一性は issue を読んだ所が記録する。
- **pickup で展開した本文を task に書き残し、読めないときに見せる** —— 生きた参照の task が写しを持つ二重の形になる(ADR 0016 が
  退けた snapshot)。登録の後に本文を要し、transcript で足りない読み手が見つからなかった。

## 帰結

- ADR 0399 決定3 の比較は残す —— 宣言の repo は publish の扉でも削除を通らずに変わる(ADR 0378 決定10)。ADR 0419・ADR 0421 は
  変えない。
- 名前を同じ repo で登録し直せば、旧い task の issue は今どおり読める。
- 限界: GitHub 上で repo を改名するか issue を別の repo へ移すと、旧い task の issue は読めない(ADR 0399 の PR の限界と同じ線)。
- memory の scope と `episodes.workspace` は名前で続く。網に出ないのでこの決定の外に置き、#3929 に起票した。
- ADR 0016・ADR 0399 に Status 追記を置いた。
