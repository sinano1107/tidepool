# 表の行で撃つ Board call の拒否も行の拒否の証拠で、その呼び出しは失敗に数えない

2026-10-06 の triage / grilling(issue #1446)で決定。行の拒否の証拠の述語(ADR 0184 決定3)を当てていたのは worker の spawn と
解除の門2の検査だけで、表の行で撃つ Board call(振り返り・AI 下書き)は同じ Claude CLI の result envelope を受けながら当てて
いなかった。#1261 で Board call は Quarantine 中の行を外して撃つと決めたが(ADR 0184 追記)、Quarantine が立つのは worker が
断られたときだけなので、worker がまれにしか選ばない行は、Board call だけが断られ続けても Quarantine にならない。経路の
`file:line` と再現は #1446 のコメントに置く。

ADR 0184 決定3 と ADR 0192 決定4 の「行の拒否の証拠は worker の spawn からしか取らない」は、当時どこで証拠を取っていたかの
記述であって線ではない —— 決定3 が引いた線は「Provider ごとに構造化されたものだけ」「401 / 429 と同じ形の述語」であり、
worker でない一発呼び出しの envelope は解除の門2の検査がすでに読んでいる。

## 決定

1. **表の行で撃つ Board call の result envelope も、行の拒否の証拠である。** 述語は worker と同じもので、文言からは推測しない。
   当てる場所は Board call が共有する一発呼び出しの口で、呼び手ごとには置かない —— 次に足される Board call が取りこぼさない
   (ADR 0184 追記4 で読み手ごとの filter を退けたのと同じ理由)。envelope が非ゼロ終了で届いても、ゼロ終了の `is_error` で
   届いても当てる。
2. **撃った行が表に残っているときだけ Quarantine を立てる。** worker と同じ条件である(#1265)。表に無い行の Quarantine は
   直す行が無いまま開き、次の無関係な表の編集が解除の門1で決着させる。
3. **断られた Board call は撃ち直しの失敗に数えない。** 1ターンも走っておらず直す判断が存在しない、という ADR 0184 決定4 の
   理由がそのまま当たる。数えなくても撃ち直しはループしない —— 次の sweep では行が Quarantine で外れ、同じティアの次の行で
   撃つか、「すべて Quarantine 中」で撃てなかったになる。
4. **呼び出しの中で次の行へ撃ち直さない。** 404 を受けるのは、行が断られてから Quarantine が立つまでの1回だけで、以後の呼び出しは
   撃つ前にその行を外す。その場で撃ち直して拾えるのは1回の commit の初回の帰責ぶんの RCA だけで、引き換えに一発呼び出しの
   道具に行の選び直しの輪が入る。下書きは人間の再操作が次の行で撃つ。
5. **事実は行の側にだけ残す。** 最初の拒否が立てる確認 question と、2度目以降の再発火が、どの用途の Board call が(対象の task が
   あればどの task で)断られたかを理由に名指す。対象の側には何も書かない —— worker の専用 event は状態遷移(`todo` 先頭への
   復帰)を運ぶから要るのであって、Board call の対象には変わる状態も、その event を読む者も無い。AI 下書きは人間が待っている
   ので、断りの理由に行が断られたことを載せて返す。

## 帰結

- 表示時翻訳は alias で撃ち、表の行ではないので、拒否されても行の Quarantine は立てない(ADR 0192 決定4 の理路は変わらない
  —— コードに置いた具体 id は、この決定の後も断られたことを観測できない)。
- 確認 question の文面は、行が外れる先を pickup だけでなく Board call も含めて書く(ADR 0184 追記1 のとおり)。
- 振り返りの Board call が 401 を動力の認証に回していない件は、この ADR の主題の外で #1457 にした。

## 退けた案

- **worker が断られたときだけ立てる今の形を決定にする** —— worker が選ばない行は、Board call だけが断られ続けても誰も気づかない。
  ADR 0184 決定2 が黙った除外にしない理由として挙げた形そのもの。
- **対象の timeline に専用の event を残す** —— 読み手がいない。行の側の question と再発火がすでに用途と対象を名指す。
- **既存の失敗 event に印を付けて数えない** —— 撃ち直しの数えと人間の打ち切りの一覧の読み手すべてに除外を足すことになる。
