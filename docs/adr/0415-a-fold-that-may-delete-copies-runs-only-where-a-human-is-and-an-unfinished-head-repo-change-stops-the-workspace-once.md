# 写しを消しうる畳みは人間のいる所でだけ行い、終わっていない出元 repo の変更は workspace を1回止める

**Status: 取り下げ。[ADR 0422](0422-what-the-board-last-pushed-to-a-head-repo-is-kept-per-fork-by-repository-id-and-a-head-repo-change-does-not-forget-it.md) が置き換える —— 盤面が出元 repo へ最後に push した値を fork ごとに持ち、出元 repo の変更で消さないので、前方向の畳みは消しうる写しを持たず、行を書くだけの畳みとして行き先の検査が人間を待たずに行う。決定1〜4 は対象が無い(2026-11-26、issue #3851)。**

2026-11-25 の grilling(issue #3797)で決定。ADR 0395 決定2 は出元 repo の変更を ADR 0391 の形(予告 → 書く → 検査が畳む)に載せた。
ところが出元 repo は repo と違って差し替えられるので、前方向の畳みは古い fork の写し(`refs/remotes/head-repo/*`)を消す。その結果、
行き先を読むだけの検査が ref を書いていた。扉が途中で死んで予告が残ると、次に行き先を読んだ呼び手がこの書き込みを引き受け、git が
落ちたときの扱いは呼び手に任された。収束は根ごとの昇格失敗 question を立てた(実測)—— ADR 0403 決定4 が退けた形である。pickup・poll・
無人 merge の tick はそれぞれ別の扱いに読める(コード読み)。実測と経路は #3797 のコメントに置く。

## 決定

1. **写しを消しうる畳みは、人間のいる所でだけ行う。** 行う所は、出元 repo の扉と、workspace の Quarantine の受理の2つ。行を書くだけの
   畳み(後ろ方向、同じ repo への畳み、publish の覚えた repo —— ADR 0391 決定3・4)は、今どおり行き先の検査が人間を待たずに行う。軸は
   「repo か出元 repo か」でなく「その畳みが写しを消しうるか」である。repo は差し替えられず(publish は無しから有りの1方向)、消す写しが
   生まれないので、repo の側に人間を待つ畳みは無い。
2. **行き先の検査は、宣言が予告の「次」と一致する行に当たったら、畳まずに workspace の Quarantine を立てて投げる。** 初めて出元 repo を
   置く予告(前の値が無い)も、外す予告(「次」が無しで、宣言も無し)も同じ線で止める —— 消すものがあるかを見分けるには checkout の
   ref を読むことになり、読む経路に git が戻る。
   投げる型は覚えた repo の食い違いの下位型で、「投げた側がもう Quarantine を立てた」と読む既存の呼び手がそのまま受ける。
3. **受理が畳む。** 回答は、古い写しを消して変更を終える。git が落ちる間の回答は、その文つきで拒まれる(ADR 0403 決定4 の受理と同じ)。
   変更をやめる出口は扉で、出元 repo を戻すか外す。workspace の Quarantine は冪等で、別の理由で既に開いていれば文面はその理由の
   ままなので、その受理も畳み、受理の応答が「変更を終えて写しを消した」と伝える —— 畳まなければ回答の直後にもう一度止まり、消す
   写しは人間が扉で頼んだ変更の残りである。
4. **扉自身の最後の畳みが落ちても、扉は Quarantine を立てない。** 人間にエラーを返し、止まりは次に行き先を読んだ1点が立てる
   (ADR 0403 決定5 の「立てるのは1点で、呼び手は何もしない」)。

## 退けた案

- **今の位置のまま、畳みの git の失敗だけを検査の中で Quarantine に変える。** 中断した扉が人間を待たずに完了する性質は残るが、読む経路が
  ref を書く構造が残る。
- **読み手は畳まず、予告中を一致として通す。** 写しを消す前に新しい fork の行き先を使うと、古い fork の写しを新しい fork のものと読み、
  push の条件と巻き戻しの検知(ADR 0376 決定2・6)を誤る。写しを読む全員に予告中の扱いを教えることになる。
- **repo の側も人間を待たせて揃える。** 守るものが無いのに、中断した publish のたびに回答が1回増える。

## 帰結

- 代償: 出元 repo の扉が途中で死ぬか、最後の畳みが落ちた後は、人間の回答が1回要る。ADR 0403 決定4 と同じく受け入れる。
