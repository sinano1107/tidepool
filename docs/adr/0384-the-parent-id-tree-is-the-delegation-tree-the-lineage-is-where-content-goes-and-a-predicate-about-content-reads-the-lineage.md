# `parent_id` の木は委譲の木で、系譜は中身の行き先 —— 中身についての述語は系譜で読む

2026-11-19 の grilling(issue #1796)で決定。ADR 0372 決定4 の後、別の workspace の子は親のブランチに帰らず、自分の保護ブランチへ根として
着地する。一方で `parent_id` の上では親の子のままなので、同じ task の集合に形の違う木が2本できる。今の読み手はどれも `parent_id` を読むので、
中身について判断する述語が食い違う —— 親のレビューに載らない子がレビューされない(#3225)、cancel が「捨てる」と出した子が着地する(#3270)、
運ばれない祖先の PR を着地が待つ(`openPrRootAbove`)。読み手の一覧と `file:line` は #1796 に置く。コードと ADR の読みで決めていて、盤面は
走らせていない。

## 決定

1. **`parent_id` は委譲の木である(ADR 0031)。系譜は中身の行き先である(ADR 0053 / ADR 0372 決定4)。** 別の workspace の子も子のままで、
   親は未決着の子を待ち、子が決着するまで完了できず、決着した子の成果を文脈に受け取る —— これらは委譲についての読みなので `parent_id` で読む。
   ブランチの中身を判定・運搬する述語は系譜で読む。2本が分かれるのは workspace を跨ぐところだけではない —— 透明な review、着地済みの祖先
   (ADR 0105)、失われたブランチ(ADR 0380)、固定されていない祖先でも分かれる。
2. **完了時レビューの根は2段で読む。** 列だけで計算する述語(ADR 0209 で WebUI と拒否が共有する)は、「`parent_id` を持ち、自分の
   workspace の列が親の導出と違う work」を根と同じに扱う —— 親を持っても完了時レビューが立ち、その子への `review_flag` は不発の値として
   拒む(ADR 0111 追記7・8)。完了の扉は起票を系譜で決め、数える祖先が残らない work には、述語が子と読んでも完了時レビューを立てる。
   述語が子、扉が根と読む形では `review_flag` が受け付けられても結果は変わらないので、この食い違いは許す。逆に、親と違う workspace でも
   同じ workspace の祖父母のブランチに中身が入る子(G(B) → P(A) → C(B))は、述語が根と読み、C と G の両方がレビューされる。稀な形なので許す。
3. **「成果が捨てられた」の cancelled の項(ADR 0271 決定1)は、cancelled の祖先の列と自分の導出が同じときだけ数える。** 項の理由
   (done の子の成果は祖先のブランチに載っているので、祖先の cancel で帰り先が死ぬ)は中身についてのものである。比べられるように、cancel は
   列の空の task(cascade で一緒に cancel される子孫を含む)の列に、その時点の導出(祖先 → 既定)を書き、書いた名前と出所を cancel の event に
   残す —— cancel された task の場所はもう変わらず、書かないと既定の差し替えで導出が動き、判定が後から反転する。自分の側は空なら導出で読む
   —— 書かれた列どうしで比べると、空の列の修理子がブランチを持たずに cancel された祖先の下で立つ(ADR 0380 決定6 が退けた形)。別の
   workspace の完了済みの子は捨てられず、レビューも倒れず、自分の保護ブランチへ着地する。cancel の面は、その子を捨てるものでなく別の場所で
   独立して着地するものとして見せる。
4. **子が親の導出と同じ workspace を明示したら、受けて保存しない。** ADR 0290 決定1・2 が review の子にしている扱いを、全 type の子に広げる。
   違う名前は今どおり保存する。人間が親と同じ名前を選ぶのは「親と一緒」の意味で、保存すると、既定の差し替えの後に子が黙って別の
   workspace の子になる。
5. **親の着地の門が数える未決着の付帯子は、系譜の部分木に限る。** 親の中身に入らない別の workspace の子孫のレビューは、親の着地を止めない。
6. **ほかに `parent_id` を読む述語は、委譲と中身のどちらについての述語かで仕分ける。** 全件の仕分けは #1796 の spec が持つ。

## 退けた形

- **別の workspace の子を根として登録し、出所のリンクだけ残す** —— 委譲の木が場所を跨いでよい(ADR 0031)ことを崩し、親の待ちと成果の
  受け渡しを失う。
- **1本の述語で系譜を読む** —— 系譜は決着済みの祖先について git を読むので、列だけの述語(ADR 0209)に入らない。
- **cancel も委譲で読み、別の workspace の子の着地を止める** —— 項の理由が中身についてのものなので、理由の当たらない子を巻き込む。止めたい
  人間には着地の question がある。
- **cancel で焼き付けず、導出どうしで比べる** —— 未固定のまま cancel された祖先の導出が既定の差し替えで動き、捨てられたかが後から反転する。
